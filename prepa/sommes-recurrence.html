Sommes et récurrence

Le symbole \(\Sigma\) pour écrire des sommes de façon compacte, et le raisonnement par récurrence pour démontrer une propriété pour tous les entiers. Ce sont deux outils que tu utiliseras dès les premières semaines de prépa, presque dans chaque chapitre.

Prérequis : suites, logique.

1. Le symbole Σ

Notation

\(\displaystyle\sum_{k=1}^{n} a_k = a_1 + a_2 + \dots + a_n\) se lit « somme des \(a_k\) pour \(k\) allant de 1 à \(n\) ». La lettre \(k\) est muette : on peut la remplacer par \(i\) ou \(j\). La somme \(\displaystyle\sum_{k=p}^{n} a_k\) contient \(n - p + 1\) termes. Ex. : \(\displaystyle\sum_{k=0}^{4} 2^k = 1 + 2 + 4 + 8 + 16 = 31\).

Règles de calcul

  • Linéarité : \(\displaystyle\sum (a_k + b_k) = \sum a_k + \sum b_k\) et \(\displaystyle\sum \lambda a_k = \lambda\sum a_k\). Attention : \(\displaystyle\sum a_kb_k \neq \sum a_k \times \sum b_k\).
  • Somme d'une constante : \(\displaystyle\sum_{k=1}^{n} c = nc\).
  • Changement d'indice : en posant \(j = k + 1\), \(\displaystyle\sum_{k=0}^{n-1} a_{k+1} = \sum_{j=1}^{n} a_j\) (on décale aussi les bornes).
  • Télescopage : \(\displaystyle\sum_{k=1}^{n} (u_{k+1} - u_k) = u_{n+1} - u_1\) (tous les termes intermédiaires s'annulent deux à deux).
  • Relation de Chasles : \(\displaystyle\sum_{k=1}^{n} a_k = \sum_{k=1}^{m} a_k + \sum_{k=m+1}^{n} a_k\).

Sommes usuelles (à connaître par cœur)

\[\sum_{k=1}^{n} k = \frac{n(n+1)}{2} \qquad \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6} \qquad \sum_{k=1}^{n} k^3 = \left(\frac{n(n+1)}{2}\right)^2 \qquad \sum_{k=0}^{n} q^k = \frac{1 - q^{n+1}}{1 - q}\ (q \neq 1)\]

Produits et factorielle

\(\displaystyle\prod_{k=1}^{n} a_k = a_1 \times a_2 \times \dots \times a_n\). La factorielle : \(n! = \displaystyle\prod_{k=1}^{n} k = 1 \times 2 \times \dots \times n\), avec \(0! = 1\) ; \(5! = 120\). Elle sert à compter : il y a \(n!\) façons de ranger \(n\) objets, et \(\dbinom nk = \dfrac{n!}{k!(n-k)!}\).

Exemple 1 — télescopage

Calculer \(\displaystyle S_n = \sum_{k=1}^{n} \frac{1}{k(k+1)}\) en remarquant que \(\dfrac{1}{k(k+1)} = \dfrac1k - \dfrac{1}{k+1}\).

Solution

\(S_n = \left(1 - \tfrac12\right) + \left(\tfrac12 - \tfrac13\right) + \dots + \left(\tfrac1n - \tfrac{1}{n+1}\right) = 1 - \dfrac{1}{n+1} = \dfrac{n}{n+1}\), qui tend vers 1.

Exemple 2 — linéarité

Calculer \(\displaystyle\sum_{k=1}^{n} (2k + 3)\).

Solution

\(2\displaystyle\sum k + \sum 3 = n(n+1) + 3n = n^2 + 4n\).

2. Le raisonnement par récurrence

Principe

Soit \(P(n)\) une propriété qui dépend d'un entier \(n\). Si :

  1. Initialisation : \(P(n_0)\) est vraie ;
  2. Hérédité : pour tout \(n \geq n_0\), si \(P(n)\) est vraie, alors \(P(n+1)\) est vraie ;

alors \(P(n)\) est vraie pour tout \(n \geq n_0\). (Image : une rangée de dominos — le premier tombe, et chacun fait tomber le suivant.)

Rédaction type

  1. Énoncer clairement \(P(n)\).
  2. Initialisation : vérifier \(P(n_0)\) par un calcul.
  3. Hérédité : « Soit \(n \geq n_0\) tel que \(P(n)\) est vraie (hypothèse de récurrence). Montrons \(P(n+1)\). » Puis utiliser l'hypothèse dans le calcul.
  4. Conclusion : « Par récurrence, \(P(n)\) est vraie pour tout \(n \geq n_0\). »

Pièges

  • Oublier l'initialisation : « \(n + 1 > n + 2\) » est héréditaire mais fausse pour tout \(n\) !
  • Supposer « pour tout \(n\), \(P(n)\) » dans l'hérédité : c'est ce qu'on veut démontrer. On suppose \(P(n)\) pour un \(n\) fixé.
  • Ne pas utiliser l'hypothèse de récurrence : si elle ne sert pas, la récurrence est probablement inutile ou mal faite.

Exemple 3 — somme des carrés

Montrer que pour tout \(n \geq 1\), \(\displaystyle\sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}\).

Solution

Initialisation : \(1 = \dfrac{1 \times 2 \times 3}{6}\). Hérédité : si c'est vrai au rang \(n\), alors \[\begin{aligned} \sum_{k=1}^{n+1} k^2 &= \frac{n(n+1)(2n+1)}{6} + (n+1)^2 \\ &= \frac{(n+1)\left(2n^2 + 7n + 6\right)}{6} \\ &= \frac{(n+1)(n+2)(2n+3)}{6}, \end{aligned}\] qui est la formule au rang \(n+1\).

Exemple 4 — inégalité de Bernoulli

Montrer que pour tout réel \(x \geq -1\) et tout entier \(n \geq 0\), \((1 + x)^n \geq 1 + nx\).

Solution

Rang 0 : \(1 \geq 1\). Si \((1 + x)^n \geq 1 + nx\), on multiplie par \(1 + x \geq 0\) (le sens est conservé) : \((1 + x)^{n+1} \geq (1 + nx)(1 + x) = 1 + (n+1)x + nx^2 \geq 1 + (n+1)x\).

3. L'essentiel à retenir

Formulaire

  • \(\sum_{k=p}^{n}\) contient \(n - p + 1\) termes ; linéarité ; changement d'indice ; télescopage \(\sum (u_{k+1} - u_k) = u_{n+1} - u_1\).
  • \(\sum k = \frac{n(n+1)}{2}\), \(\sum k^2 = \frac{n(n+1)(2n+1)}{6}\), \(\sum k^3 = \left(\frac{n(n+1)}{2}\right)^2\), \(\sum q^k = \frac{1 - q^{n+1}}{1 - q}\).
  • \(n! = 1 \times 2 \times \dots \times n\), \(0! = 1\).
  • Récurrence : initialisation + hérédité (avec l'hypothèse au rang \(n\)) + conclusion.

4. Manipuler

Visualiser \(\sum k\) et \(\sum k^2\)

Chaque barre est un terme. La courbe en pointillés est la formule fermée : elle coïncide toujours avec la somme cumulée (points).

Les dominos de la récurrence

Initialisation = pousser le premier domino. Hérédité = chaque domino fait tomber le suivant. Si l'une des deux manque, rien ne garantit la chute de tous.

Entraînement : calculer une somme

Valeur exacte (entier ou fraction).

5. En prépa

Ce qui t'attend

  • Récurrence double et forte, sommes doubles \(\sum_{i}\sum_j\), produits \(\prod\), factorielle.
  • Formule du binôme de Newton \((a + b)^n = \sum_{k=0}^{n}\binom nk a^kb^{n-k}\) (démontrée par récurrence).
  • Séries numériques (sommes infinies) en 2e année.

Quiz

\(\displaystyle\sum_{k=3}^{10} 5 =\)

  1. \(35\)
  2. \(40\)
  3. \(50\)
  4. \(5\)

8 termes (de 3 à 10) égaux à 5.

Dans une récurrence, l'hérédité consiste à montrer :

  1. \(\mathcal P(n)\) pour tout \(n\)
  2. \(\mathcal P(n+1) \Rightarrow \mathcal P(n)\)
  3. \(\mathcal P(n) \Rightarrow \mathcal P(n+1)\) pour tout \(n \geq n_0\)
  4. \(\mathcal P(0)\)

On suppose \(\mathcal P(n)\) pour un \(n\) fixé et on en déduit \(\mathcal P(n+1)\). Écrire « supposons \(\mathcal P(n)\) vraie pour tout \(n\) » est une faute grave : c'est ce qu'on veut démontrer !

\(\displaystyle\sum_{k=1}^{n}\big((k+1)^2 - k^2\big) =\)

  1. \((n+1)^2 - 1\)
  2. \(n^2\)
  3. \(1\)
  4. \(2n\)

Télescopage : il reste le dernier moins le premier.

\(\displaystyle\sum_{k=0}^{n} 2^k =\)

  1. \(2^n\)
  2. \(2^{n+1}\)
  3. \(2^n - 1\)
  4. \(2^{n+1} - 1\)

\(\dfrac{1 - 2^{n+1}}{1 - 2}\).
