Sommes et récurrence

Le symbole \(\Sigma\) est partout en prépa. Savoir le manipuler (changement d'indice, télescopage, sommes usuelles) et démontrer une propriété par récurrence sont deux compétences attendues dès les premières semaines.

Prérequis : suites arithmétiques et géométriques, logique.

1. Le symbole Σ

Notation

\(\displaystyle\sum_{k=1}^{n} a_k = a_1 + a_2 + \dots + a_n\). L'indice \(k\) est muet : \(\sum_{k=1}^n k^2 = \sum_{i=1}^n i^2\). Nombre de termes de \(\sum_{k=p}^{n}\) : \(n - p + 1\).

Règles de calcul

  • Linéarité : \(\sum (\lambda a_k + \mu b_k) = \lambda\sum a_k + \mu\sum b_k\). Une constante : \(\sum_{k=1}^n c = nc\).
  • Changement d'indice : \(\sum_{k=1}^{n} a_{k-1} = \sum_{j=0}^{n-1} a_j\) (on pose \(j = k - 1\) et on décale les bornes).
  • Télescopage : \(\sum_{k=1}^{n} (a_{k+1} - a_k) = a_{n+1} - a_1\).
  • Attention : \(\sum a_kb_k \neq \left(\sum a_k\right)\left(\sum b_k\right)\) en général.

Sommes usuelles (à connaître par cœur)

\[\sum_{k=1}^{n} k = \frac{n(n+1)}{2} \qquad \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6} \qquad \sum_{k=0}^{n} q^k = \frac{1 - q^{n+1}}{1 - q}\ (q \neq 1)\]

Exemple 1 — télescopage

Calculer \(S_n = \displaystyle\sum_{k=1}^{n} \frac{1}{k(k+1)}\).

Solution

\(\dfrac{1}{k(k+1)} = \dfrac1k - \dfrac{1}{k+1}\) (réduire au même dénominateur pour vérifier). \(S_n = \left(1 - \tfrac12\right) + \left(\tfrac12 - \tfrac13\right) + \dots + \left(\tfrac1n - \tfrac1{n+1}\right) = 1 - \dfrac{1}{n+1}\). Donc \(S_n \to 1\).

Exemple 2 — linéarité

Calculer \(\displaystyle\sum_{k=1}^{n} (2k + 3)\).

Solution

\(2\sum k + \sum 3 = n(n+1) + 3n = n^2 + 4n\).

2. Le raisonnement par récurrence

Principe

Soit \(\mathcal P(n)\) une propriété dépendant de \(n \in \mathbb{N}\). Si :

  1. Initialisation : \(\mathcal P(n_0)\) est vraie ;
  2. Hérédité : pour tout \(n \geq n_0\), \(\mathcal P(n) \Rightarrow \mathcal P(n+1)\) ;

alors \(\mathcal P(n)\) est vraie pour tout \(n \geq n_0\). (Image : une rangée infinie de dominos.)

Rédaction type

« Pour \(n \in \mathbb{N}^*\), notons \(\mathcal P(n)\) : … »
« Initialisation : pour \(n = 1\), … donc \(\mathcal P(1)\) est vraie. »
« Hérédité : soit \(n \geq 1\) tel que \(\mathcal P(n)\) soit vraie. Montrons \(\mathcal P(n+1)\). … »
« Conclusion : par récurrence, \(\mathcal P(n)\) est vraie pour tout \(n \geq 1\). »

Exemple 3 — somme des carrés

Démontrer que pour tout \(n \geq 1\), \(\displaystyle\sum_{k=1}^n k^2 = \frac{n(n+1)(2n+1)}{6}\).

Solution

Initialisation : \(n = 1\) : \(1 = \dfrac{1 \times 2 \times 3}{6}\). ✓

Hérédité : supposons la formule vraie au rang \(n\). Alors \[\begin{aligned} \sum_{k=1}^{n+1} k^2 &= \frac{n(n+1)(2n+1)}{6} + (n+1)^2 \\ &= \frac{(n+1)\big[n(2n+1) + 6(n+1)\big]}{6} \\ &= \frac{(n+1)(2n^2 + 7n + 6)}{6}. \end{aligned}\] Or \(2n^2 + 7n + 6 = (n+2)(2n+3)\), d'où \(\dfrac{(n+1)(n+2)(2(n+1)+1)}{6}\) : c'est \(\mathcal P(n+1)\). ✓

Conclusion : la formule est vraie pour tout \(n \geq 1\). ∎

Exemple 4 — inégalité de Bernoulli

Montrer que pour \(x > -1\) et tout \(n \in \mathbb{N}\) : \((1 + x)^n \geq 1 + nx\).

Solution

\(n = 0\) : \(1 \geq 1\). Hérédité : \((1+x)^{n+1} = (1+x)^n(1+x) \geq (1 + nx)(1 + x)\) car \(1 + x > 0\) (on peut multiplier sans changer le sens !). Or \((1 + nx)(1+x) = 1 + (n+1)x + nx^2 \geq 1 + (n+1)x\). ∎

3. Manipuler

Visualiser \(\sum k\) et \(\sum k^2\)

Chaque barre est un terme. La courbe en pointillés est la formule fermée : elle coïncide toujours avec la somme cumulée (points).

Les dominos de la récurrence

Initialisation = pousser le premier domino. Hérédité = chaque domino fait tomber le suivant. Si l'une des deux manque, rien ne garantit la chute de tous.

Entraînement : calculer une somme

Valeur exacte (entier ou fraction).

4. En prépa

Ce qui t'attend

  • Récurrence double et forte, sommes doubles \(\sum_{i}\sum_j\), produits \(\prod\), factorielle.
  • Formule du binôme de Newton \((a + b)^n = \sum_{k=0}^{n}\binom nk a^kb^{n-k}\) (démontrée par récurrence).
  • Séries numériques (sommes infinies) en 2e année.

Quiz

\(\displaystyle\sum_{k=3}^{10} 5 =\)

  1. \(35\)
  2. \(40\)
  3. \(50\)
  4. \(5\)

8 termes (de 3 à 10) égaux à 5.

Dans une récurrence, l'hérédité consiste à montrer :

  1. \(\mathcal P(n)\) pour tout \(n\)
  2. \(\mathcal P(n+1) \Rightarrow \mathcal P(n)\)
  3. \(\mathcal P(n) \Rightarrow \mathcal P(n+1)\) pour tout \(n \geq n_0\)
  4. \(\mathcal P(0)\)

On suppose \(\mathcal P(n)\) pour un \(n\) fixé et on en déduit \(\mathcal P(n+1)\). Écrire « supposons \(\mathcal P(n)\) vraie pour tout \(n\) » est une faute grave : c'est ce qu'on veut démontrer !

\(\displaystyle\sum_{k=1}^{n}\big((k+1)^2 - k^2\big) =\)

  1. \((n+1)^2 - 1\)
  2. \(n^2\)
  3. \(1\)
  4. \(2n\)

Télescopage : il reste le dernier moins le premier.

\(\displaystyle\sum_{k=0}^{n} 2^k =\)

  1. \(2^n\)
  2. \(2^{n+1}\)
  3. \(2^n - 1\)
  4. \(2^{n+1} - 1\)

\(\dfrac{1 - 2^{n+1}}{1 - 2}\).
