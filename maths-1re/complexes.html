Nombres complexes : forme algébrique et trigonométrique

Un nombre complexe, c'est un point du plan (ou un vecteur) qu'on sait additionner et multiplier. En électricité, ils représentent tensions et courants sinusoïdaux : amplitude = module, déphasage = argument. Cette année : formes algébrique et trigonométrique.

Prérequis : trigonométrie, calcul littéral.

1. Forme algébrique

Définition

Il existe un nombre \(i\) tel que \(i^2 = -1\). Tout nombre complexe s'écrit de façon unique \(z = a + ib\) avec \(a, b\) réels : \(a = \mathrm{Re}(z)\) est la partie réelle, \(b = \mathrm{Im}(z)\) la partie imaginaire. L'ensemble des complexes est noté \(\mathbb{C}\).

Calculs

  • On calcule comme avec des réels, en remplaçant \(i^2\) par \(-1\) : \((2 + 3i)(1 - i) = 2 - 2i + 3i - 3i^2 = 5 + i\).
  • Conjugué de \(z = a + ib\) : \(\bar z = a - ib\). On a \(z\bar z = a^2 + b^2\) (un réel positif).
  • Quotient : on multiplie numérateur et dénominateur par le conjugué du dénominateur.
  • \(\overline{z + z'} = \bar z + \bar{z'}\), \(\overline{z z'} = \bar z\,\bar{z'}\), \(\overline{\left(\tfrac{z}{z'}\right)} = \tfrac{\bar z}{\bar{z'}}\).

Exemple 1

Écrire \(\dfrac{3 + i}{1 + 2i}\) sous forme algébrique.

Solution

\(\dfrac{(3 + i)(1 - 2i)}{(1 + 2i)(1 - 2i)} = \dfrac{3 - 6i + i - 2i^2}{1 + 4} = \dfrac{5 - 5i}{5} = 1 - i\).

2. Représentation, module et argument

Plan complexe

Dans un repère orthonormé direct, \(z = a + ib\) est l'affixe du point \(M(a\,;\,b)\) et du vecteur \(\overrightarrow{OM}\). Le conjugué \(\bar z\) correspond au symétrique de \(M\) par rapport à l'axe des abscisses.

Module et argument

Le module \(|z| = \sqrt{a^2 + b^2} = OM\). Pour \(z \neq 0\), un argument \(\arg z\) est une mesure de l'angle \((\vec{u}, \overrightarrow{OM})\), défini à \(2\pi\) près.

Propriétés du module

\(|zz'| = |z|\,|z'|\), \(\left|\dfrac{z}{z'}\right| = \dfrac{|z|}{|z'|}\), \(|\bar z| = |z|\), \(z\bar z = |z|^2\).

3. Forme trigonométrique

Passage d'une forme à l'autre

Si \(r = |z|\) et \(\theta = \arg z\), alors \[z = r(\cos\theta + i\sin\theta), \qquad a = r\cos\theta, \quad b = r\sin\theta, \quad \cos\theta = \frac{a}{r}, \quad \sin\theta = \frac{b}{r}.\]

Méthode : forme algébrique → trigonométrique

  1. Calculer \(r = \sqrt{a^2 + b^2}\).
  2. Calculer \(\cos\theta = a/r\) et \(\sin\theta = b/r\), reconnaître des valeurs remarquables.
  3. Écrire \(z = r(\cos\theta + i\sin\theta)\).

Exemple 2

Forme trigonométrique de \(z = 1 + i\sqrt3\) et de \(w = -2 - 2i\).

Solution

\(|z| = \sqrt{1 + 3} = 2\), \(\cos\theta = \tfrac12\), \(\sin\theta = \tfrac{\sqrt3}{2}\) : \(\theta = \tfrac{\pi}{3}\), donc \(z = 2\left(\cos\tfrac{\pi}{3} + i\sin\tfrac{\pi}{3}\right)\).

\(|w| = 2\sqrt2\), \(\cos\theta = \sin\theta = -\tfrac{\sqrt2}{2}\) : \(\theta = -\tfrac{3\pi}{4}\).

En Terminale et en prépa

La notation exponentielle \(z = re^{i\theta}\) et les produits sous forme trigonométrique (\(\arg(zz') = \arg z + \arg z'\)) arrivent en Terminale : voir Nombres complexes (Terminale).

4. Manipuler

Le point \(M\) d'affixe \(z = a + ib\)

Le cercle a pour rayon \(|z|\) ; l'arc mesure l'argument. Le point gris est \(\bar z\).

Entraînement : calculs avec les complexes

Valeur exacte ou arrondie à 0,01 près ; les arguments en degrés, dans \(]-180\,;\,180]\).

Quiz

\(i^3 =\)

  1. \(1\)
  2. \(i\)
  3. \(-i\)
  4. \(-1\)

\(i^3 = i^2 \times i = -i\).

Le module de \(3 - 4i\) est :

  1. \(5\)
  2. \(7\)
  3. \(-1\)
  4. \(25\)

\(\sqrt{9 + 16} = 5\).

Un argument de \(-5i\) est :

  1. \(\tfrac{\pi}{2}\)
  2. \(\pi\)
  3. \(0\)
  4. \(-\tfrac{\pi}{2}\)

Le point \((0\,;\,-5)\) est sur la partie négative de l'axe des ordonnées.

\((1 + i)(1 - i) =\)

  1. \(0\)
  2. \(2\)
  3. \(2i\)
  4. \(1 - i^2 i\)

\(z\bar z = 1^2 + 1^2 = 2\).
