Nombres complexes : forme algébrique et trigonométrique

Un nombre complexe, c'est un point du plan (ou une flèche) qu'on sait additionner et multiplier comme un nombre. En électricité, ils servent à décrire les tensions et les courants alternatifs : la longueur de la flèche donne l'amplitude, son angle donne le décalage (le déphasage). Cette année : la forme algébrique et la forme trigonométrique.

Prérequis : trigonométrie, calcul littéral.

1. Forme algébrique

Définition

On admet qu'il existe un nombre, noté \(i\), tel que \(i^2 = -1\) (aucun nombre réel ne vérifie cela, d'où le nom de nombre « imaginaire »). Tout nombre complexe s'écrit de façon unique \(z = a + ib\) avec \(a\) et \(b\) réels :

  • \(a = \mathrm{Re}(z)\) est la partie réelle, \(b = \mathrm{Im}(z)\) la partie imaginaire ;
  • si \(b = 0\), \(z\) est un réel ; si \(a = 0\), \(z\) est un imaginaire pur.

L'ensemble des nombres complexes est noté \(\mathbb{C}\). Deux complexes sont égaux si et seulement s'ils ont la même partie réelle et la même partie imaginaire. (En électricité, on écrit souvent \(j\) au lieu de \(i\), car \(i\) désigne l'intensité.)

Calculer

  • On calcule comme avec des réels, puis on remplace \(i^2\) par \(-1\) : \((2 + 3i)(1 - i) = 2 - 2i + 3i - 3i^2 = 5 + i\).
  • Puissances de \(i\) : \(i^2 = -1\), \(i^3 = -i\), \(i^4 = 1\), puis ça recommence.
  • Conjugué de \(z = a + ib\) : \(\bar z = a - ib\) (on change le signe de la partie imaginaire). On a \(z\bar z = a^2 + b^2\), un réel positif.
  • Quotient : on multiplie le haut et le bas par le conjugué du dénominateur, pour avoir un dénominateur réel.
  • Propriétés du conjugué : \(\overline{z + z'} = \bar z + \bar{z'}\), \(\overline{z z'} = \bar z\,\bar{z'}\), \(\overline{\left(\tfrac{z}{z'}\right)} = \tfrac{\bar z}{\bar{z'}}\) ; \(z + \bar z = 2\,\mathrm{Re}(z)\), \(z - \bar z = 2i\,\mathrm{Im}(z)\).

Exemple 1

Écrire \(\dfrac{3 + i}{1 + 2i}\) et \(\dfrac{1}{2 - i}\) sous forme algébrique.

Solution

\(\dfrac{(3 + i)(1 - 2i)}{(1 + 2i)(1 - 2i)} = \dfrac{3 - 6i + i - 2i^2}{1 + 4} = \dfrac{5 - 5i}{5} = 1 - i\).

\(\dfrac{1}{2 - i} = \dfrac{2 + i}{(2 - i)(2 + i)} = \dfrac{2 + i}{5} = \dfrac25 + \dfrac15 i\).

2. Représentation, module et argument

Le plan complexe

Dans un repère orthonormé direct, le nombre \(z = a + ib\) est l'affixe du point \(M(a\,;\,b)\) et du vecteur \(\overrightarrow{OM}\). L'axe horizontal est l'axe des réels, l'axe vertical celui des imaginaires purs. Le conjugué \(\bar z\) correspond au symétrique de \(M\) par rapport à l'axe horizontal. L'affixe de \(\overrightarrow{AB}\) est \(z_B - z_A\), et celle du milieu de \([AB]\) est \(\dfrac{z_A + z_B}{2}\).

Module et argument

Le module de \(z\) est la longueur \(OM\) : \(|z| = \sqrt{a^2 + b^2}\). Ainsi \(AB = |z_B - z_A|\). Pour \(z \neq 0\), un argument de \(z\), noté \(\arg z\), est une mesure de l'angle orienté entre l'axe des réels et \(\overrightarrow{OM}\). Il est défini à \(2\pi\) près.

Propriétés du module

\(|zz'| = |z|\,|z'|\), \(\left|\dfrac{z}{z'}\right| = \dfrac{|z|}{|z'|}\), \(|\bar z| = |z|\), \(z\bar z = |z|^2\), \(|z| = 0 \iff z = 0\).

Arguments à connaître

Réel positif : \(\arg = 0\) ; réel négatif : \(\pi\) ; \(ib\) avec \(b > 0\) : \(\tfrac{\pi}{2}\) ; avec \(b < 0\) : \(-\tfrac{\pi}{2}\) ; \(\arg \bar z = -\arg z\).

3. Forme trigonométrique

Passer d'une forme à l'autre

Si \(r = |z|\) et \(\theta = \arg z\), alors \[z = r(\cos\theta + i\sin\theta), \qquad a = r\cos\theta, \quad b = r\sin\theta, \quad \cos\theta = \frac{a}{r}, \quad \sin\theta = \frac{b}{r}.\]

Méthode : forme algébrique → forme trigonométrique

  1. Calculer \(r = \sqrt{a^2 + b^2}\).
  2. Calculer \(\cos\theta = a/r\) et \(\sin\theta = b/r\), puis reconnaître un angle du cercle trigonométrique (les signes indiquent le quart du cercle).
  3. Écrire \(z = r(\cos\theta + i\sin\theta)\).

Exemple 2

Forme trigonométrique de \(z = 1 + i\sqrt3\) et de \(w = -2 - 2i\).

Solution

\(|z| = \sqrt{1 + 3} = 2\), \(\cos\theta = \tfrac12\), \(\sin\theta = \tfrac{\sqrt3}{2}\) : \(\theta = \tfrac{\pi}{3}\), donc \(z = 2\left(\cos\tfrac{\pi}{3} + i\sin\tfrac{\pi}{3}\right)\).

\(|w| = 2\sqrt2\), \(\cos\theta = \sin\theta = -\tfrac{\sqrt2}{2}\) (les deux négatifs : en bas à gauche) : \(\theta = -\tfrac{3\pi}{4}\).

En Terminale et en prépa

La notation exponentielle \(z = re^{i\theta}\) et les règles \(\arg(zz') = \arg z + \arg z'\) arrivent en Terminale : voir Nombres complexes (Terminale).

4. L'essentiel à retenir

Formulaire

  • \(i^2 = -1\) ; \(z = a + ib\), \(\mathrm{Re}(z) = a\), \(\mathrm{Im}(z) = b\) ; \(\bar z = a - ib\), \(z\bar z = a^2 + b^2\).
  • Quotient : multiplier par le conjugué du dénominateur.
  • \(|z| = \sqrt{a^2 + b^2}\), \(AB = |z_B - z_A|\), milieu \(\dfrac{z_A + z_B}{2}\) ; \(|zz'| = |z||z'|\).
  • \(z = r(\cos\theta + i\sin\theta)\), \(a = r\cos\theta\), \(b = r\sin\theta\).

5. Manipuler

Le point \(M\) d'affixe \(z = a + ib\)

Le cercle a pour rayon \(|z|\) ; l'arc mesure l'argument. Le point gris est \(\bar z\).

Entraînement : calculs avec les complexes

Valeur exacte ou arrondie à 0,01 près ; les arguments en degrés, dans \(]-180\,;\,180]\).

Quiz

  1. \(1\)
  2. \(i\)
  3. \(-i\)
  4. \(-1\)

\(i^3 = i^2 \times i = -i\).

Le module de \(3 - 4i\) est :

  1. \(5\)
  2. \(7\)
  3. \(-1\)
  4. \(25\)

\(\sqrt{9 + 16} = 5\).

Un argument de \(-5i\) est :

  1. \(\tfrac{\pi}{2}\)
  2. \(\pi\)
  3. \(0\)
  4. \(-\tfrac{\pi}{2}\)

Le point \((0\,;\,-5)\) est sur la partie négative de l'axe des ordonnées.

  1. \(0\)
  2. \(2\)
  3. \(2i\)
  4. \(1 - i^2 i\)
