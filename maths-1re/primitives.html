Primitives et méthode d'Euler

Dériver, c'est passer de la position à la vitesse. Chercher une primitive, c'est faire le chemin inverse : retrouver la position à partir de la vitesse. Et quand on ne sait pas faire le calcul exact, la méthode d'Euler construit la courbe pas à pas.

Prérequis : fonctions dérivées.

1. Définition et propriété fondamentale

Définition

Soit \(f\) une fonction définie sur un intervalle \(I\). Une primitive de \(f\) sur \(I\) est une fonction \(F\) dont la dérivée est \(f\) : \[F'(x) = f(x) \text{ pour tout } x \text{ de } I.\] Exemple : \(F(x) = x^2\) est une primitive de \(f(x) = 2x\), car \((x^2)' = 2x\). Pour vérifier qu'on a trouvé une primitive, on dérive et on doit retomber sur \(f\).

Toutes les primitives (admis)

Si \(F\) est une primitive de \(f\) sur \(I\), alors les primitives de \(f\) sont toutes les fonctions \(F + C\), où \(C\) est une constante réelle. Autrement dit, deux primitives d'une même fonction diffèrent d'une constante : leurs courbes sont « parallèles », l'une est la translation verticale de l'autre.

Il y a donc une seule primitive qui prend une valeur donnée \(y_0\) en un point \(t_0\) : on trouve \(C\) grâce à cette condition initiale.

Exemple 1 — l'idée en physique

Un mobile a une vitesse nulle à chaque instant. Que dire de sa position ?

Solution

Il ne bouge pas : sa position est constante. Une fonction dont la dérivée est nulle sur un intervalle est constante — c'est pour ça que deux primitives (même dérivée) ne diffèrent que d'une constante.

2. Primitives usuelles et règles

Tableau

\(f(t)\)une primitive \(F(t)\)
\(k\) (constante)\(kt\)
\(t\)\(\dfrac{t^2}{2}\)
\(t^2\)\(\dfrac{t^3}{3}\)
\(t^n\) (\(n \geq 0\) entier)\(\dfrac{t^{n+1}}{n + 1}\)
\(A\cos(\omega t + \varphi)\)\(\dfrac{A}{\omega}\sin(\omega t + \varphi)\)
\(A\sin(\omega t + \varphi)\)\(-\dfrac{A}{\omega}\cos(\omega t + \varphi)\)

Moyen mnémotechnique pour \(t^n\) : « on monte l'exposant de 1, puis on divise par le nouvel exposant ».

Règles (linéarité)

Une primitive de \(f + g\) est \(F + G\) ; une primitive de \(k f\) est \(k F\). Pour un polynôme, on prend donc une primitive de chaque terme. Ex. : une primitive de \(6t^2 - 4t + 5\) est \(2t^3 - 2t^2 + 5t\).

Méthode : la primitive qui vérifie une condition

  1. Écrire toutes les primitives : \(F(t) = \dots + C\).
  2. Remplacer \(t\) par \(t_0\) et écrire \(F(t_0) = y_0\).
  3. En déduire \(C\) et conclure.

Exemple 2 — retrouver la position

Un mobile a pour vitesse \(v(t) = 3t^2 - 4t + 2\) (m/s) et se trouve en \(x = 5\) m à \(t = 0\). Donner \(x(t)\).

Solution

\(x(t) = t^3 - 2t^2 + 2t + C\) et \(x(0) = C = 5\), donc \(x(t) = t^3 - 2t^2 + 2t + 5\).

Exemple 3 — de l'accélération à la position

Une voiture démarre avec une accélération constante \(a = 2\ \mathrm{m/s^2}\), vitesse et position nulles à \(t = 0\). Exprimer \(v(t)\) et \(x(t)\).

Solution

\(v' = a = 2\) donc \(v(t) = 2t + C_1\), et \(v(0) = 0\) donne \(v(t) = 2t\).

\(x' = v = 2t\) donc \(x(t) = t^2 + C_2\), et \(x(0) = 0\) donne \(x(t) = t^2\). Après 10 s : 100 m parcourus, à 20 m/s.

Exemple 4 — intensité et charge

Un courant \(i(t) = 2\cos(100\pi t)\) (A) charge une armature, avec \(q(0) = 0\). Sachant \(i = \dfrac{\mathrm{d}q}{\mathrm{d}t}\), exprimer \(q(t)\).

Solution

\(q(t) = \dfrac{2}{100\pi}\sin(100\pi t) + C\) et \(q(0) = C = 0\) : \(q(t) = \dfrac{1}{50\pi}\sin(100\pi t)\) (en coulombs).

3. Méthode d'Euler

Principe

On cherche une fonction \(y\) telle que \(y'(t) = f(t)\) et \(y(t_0) = y_0\) (c'est un « problème de Cauchy »), sans savoir écrire de primitive exacte. Idée : sur un petit pas \(h\), la courbe ressemble à sa tangente, donc \(y(t + h) \approx y(t) + h \times y'(t)\). On avance de proche en proche : \[t_{k+1} = t_k + h, \qquad y_{k+1} = y_k + h \times f(t_k).\] On relie les points \((t_k\,;\,y_k)\) : on obtient une ligne brisée qui approche la vraie courbe. Plus \(h\) est petit, meilleure est l'approximation (mais plus il faut de calculs).

def euler(f, t0, y0, h, n):
    t, y = t0, y0
    points = [(t, y)]
    for k in range(n):
        y = y + h * f(t)      # on suit la tangente sur un pas h
        t = t + h
        points.append((t, y))
    return points

print(euler(lambda t: 1 / (1 + t**2), 0, 0, 0.5, 4)[-1])   # (2.0, 1.3038...)

Exemple 5 — à la main

\(y' = 2t\), \(y(0) = 1\), pas \(h = 0{,}5\). Calculer \(y_1\) et \(y_2\), puis comparer à la solution exacte.

Solution

\(y_1 = 1 + 0{,}5 \times (2 \times 0) = 1\) ; \(y_2 = 1 + 0{,}5 \times (2 \times 0{,}5) = 1{,}5\).

Solution exacte : \(y = t^2 + 1\), donc \(y(1) = 2\). Euler sous-estime ici ; avec \(h = 0{,}1\), on trouverait \(1{,}9\).

4. L'essentiel à retenir

Formulaire

  • \(F\) primitive de \(f\) ⇔ \(F' = f\) ; toutes les primitives : \(F + C\) ; condition initiale → \(C\).
  • Primitive de \(t^n\) : \(\dfrac{t^{n+1}}{n+1}\) ; de \(k\) : \(kt\).
  • Primitive de \(A\cos(\omega t + \varphi)\) : \(\dfrac{A}{\omega}\sin(\omega t + \varphi)\) ; de \(A\sin(\omega t + \varphi)\) : \(-\dfrac{A}{\omega}\cos(\omega t + \varphi)\).
  • Physique : \(a \xrightarrow{\text{primitive}} v \xrightarrow{\text{primitive}} x\) ; \(i \to q\).
  • Euler : \(y_{k+1} = y_k + h\,f(t_k)\), \(t_{k+1} = t_k + h\).

Quiz

Une primitive de \(t \mapsto 6t^2\) est :

  1. \(12t\)
  2. \(2t^3 + 7\)
  3. \(6t^3\)
  4. \(3t^2\)

\((2t^3 + 7)' = 6t^2\) : la constante 7 ne change rien.

Une primitive de \(\cos(2t)\) est :

  1. \(\sin(2t)\)
  2. \(-\tfrac12\sin(2t)\)
  3. \(2\sin(2t)\)
  4. \(\tfrac12\sin(2t)\)

\(\left(\tfrac12\sin(2t)\right)' = \tfrac12 \times 2\cos(2t)\).

Euler avec \(y' = f(t)\) : \(y_{k+1} =\)

  1. \(y_k + h f(t_k)\)
  2. \(y_k \times h f(t_k)\)
  3. \(f(t_k + h)\)
  4. \(y_k + f(t_k)\)

On avance de \(h\) en suivant la tangente de pente \(f(t_k)\).

\(F\) et \(G\) sont deux primitives de \(f\) avec \(F(0) = 1\) et \(G(0) = 4\). Alors \(G - F\) vaut :

  1. \(0\)
  2. \(f\)
  3. la constante \(3\)
  4. on ne peut pas savoir

Elles diffèrent d'une constante, égale à \(G(0) - F(0) = 3\).
