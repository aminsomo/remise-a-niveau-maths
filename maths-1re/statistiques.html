Statistiques à deux variables

Croiser deux caractères d'une population (tableau croisé, fréquences conditionnelles), puis relier deux grandeurs mesurées (nuage de points, ajustement affine) pour interpoler ou extrapoler — comme une droite d'étalonnage en physique.

Prérequis : fréquences, moyenne (seconde), équation de droite.

1. Tableau croisé et fréquences

Définitions

Un tableau croisé d'effectifs répartit une population selon deux caractères. À partir de l'effectif total \(N\) :

  • fréquence marginale de A : \(f(A) = \dfrac{n_A}{N}\) (on lit un total de ligne ou de colonne) ;
  • fréquence conditionnelle de B parmi A : \(f_A(B) = \dfrac{n_{A \cap B}}{n_A}\) (on se restreint à la ligne ou colonne A).

2. Nuage de points et point moyen

Définitions

Une série à deux variables quantitatives \((x_i\,;\,y_i)\), \(1 \leq i \leq n\), se représente par un nuage de points. Le point moyen est \(G(\bar x\,;\,\bar y)\) avec \(\bar x = \dfrac{x_1 + \dots + x_n}{n}\) et \(\bar y = \dfrac{y_1 + \dots + y_n}{n}\).

Ajustement affine

Quand le nuage est allongé selon une droite, on l'ajuste par une droite \(y = ax + b\) : au jugé, par la droite de Mayer (passant par les points moyens des deux moitiés du nuage) ou par la méthode des moindres carrés, qui rend minimale la somme \(\sum_i \big(y_i - (ax_i + b)\big)^2\). Cette droite passe par \(G\) ; la calculatrice ou le tableur donne \(a\) et \(b\).

Interpoler, extrapoler

On remplace \(x\) par une valeur dans \(y = ax + b\). À l'intérieur du domaine des mesures, c'est une interpolation (fiable) ; au-delà, une extrapolation, à manier avec esprit critique : rien ne garantit que la tendance continue.

Exemple 2 — étalonnage d'un capteur

Un capteur donne une tension \(U\) (mV) selon la température \(\theta\) (°C) : (0 ; 2), (20 ; 41), (40 ; 79), (60 ; 122). Point moyen ? Avec l'ajustement des moindres carrés \(U = 1{,}99\,\theta + 1{,}3\), quelle température pour 100 mV ?

Solution

\(\bar\theta = 30\), \(\bar U = \tfrac{2 + 41 + 79 + 122}{4} = 61\) : \(G(30\,;\,61)\). (On vérifie que la droite passe par \(G\) : \(1{,}99 \times 30 + 1{,}3 = 61\).)

\(100 = 1{,}99\,\theta + 1{,}3 \iff \theta \approx 49{,}6\) °C (interpolation).

3. Manipuler

Nuage de points et droite des moindres carrés

Augmente le bruit : le nuage s'étale et l'ajustement devient moins pertinent. Le point orange est le point moyen \(G\).

Entraînement : fréquences et ajustement

Fréquences en décimal (ex. 0,25) ; valeurs arrondies à 0,01 près.

Quiz

Avec le tableau du §1, la fréquence des moteurs de l'usine 1 parmi ceux sans panne vaut :

  1. \(\tfrac{588}{600}\)
  2. \(\tfrac{588}{1000}\)
  3. \(\tfrac{588}{972}\)
  4. \(\tfrac{600}{1000}\)

On se restreint à la colonne « sans panne » (972 moteurs).

La droite des moindres carrés passe toujours par :

  1. le point moyen
  2. l'origine
  3. le premier point
  4. le point le plus haut

C'est une propriété de l'ajustement par les moindres carrés.

Utiliser un ajustement pour prévoir une valeur très loin des mesures, c'est :

  1. une interpolation sûre
  2. une moyenne
  3. une fréquence conditionnelle
  4. une extrapolation, à prendre avec prudence

Hors du domaine observé, le modèle peut cesser d'être valable.

Points (1 ; 3), (2 ; 5), (3 ; 10). Le point moyen est :

  1. (3 ; 18)
  2. (2 ; 6)
  3. (2 ; 5)
  4. (6 ; 18)

\(\bar x = 2\), \(\bar y = 18/3 = 6\).
