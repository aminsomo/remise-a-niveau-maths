Fonctions polynômes du second degré

Trajectoire d'un projectile, aire à maximiser, puissance dissipée \(P = RI^2\) : le second degré est partout. Tu sauras associer une parabole à son expression, trouver son sommet par symétrie et étudier son signe.

Prérequis : développer, factoriser, résoudre une équation produit nul.

1. Les fonctions polynômes de degré 2

Définition

Une fonction polynôme de degré 2 s'écrit \(f(x) = ax^2 + bx + c\) avec \(a \neq 0\). Sa courbe est une parabole.

Trois formes à reconnaître

  • \(x \mapsto ax^2\) : sommet en \(O\), axe de symétrie l'axe des ordonnées.
  • \(x \mapsto ax^2 + b\) : la même parabole translatée verticalement de \(b\) ; sommet \((0\,;\,b)\).
  • \(x \mapsto a(x - x_1)(x - x_2)\) : forme factorisée, la parabole coupe l'axe des abscisses en \(x_1\) et \(x_2\).

Si \(a > 0\), la parabole est « tournée vers le haut » (minimum) ; si \(a < 0\), « vers le bas » (maximum).

2. Sommet et axe de symétrie

Propriété

La parabole admet un axe de symétrie vertical d'équation \(x = \alpha\), qui passe par son sommet \(S(\alpha\,;\,f(\alpha))\). Deux points de même ordonnée sont symétriques par rapport à cet axe : si \(f(x_1) = f(x_2)\), alors \(\alpha = \dfrac{x_1 + x_2}{2}\).

Méthode : trouver le sommet sans formule

On résout \(f(x) = c\) (avec \(c = f(0)\)) : \(ax^2 + bx = 0 \iff x(ax + b) = 0\), donc \(x = 0\) ou \(x = -\tfrac{b}{a}\). L'axe passe au milieu : \(\alpha = -\dfrac{b}{2a}\).

Exemple 1 — hauteur d'un ballon

La hauteur (en m) d'un ballon est \(h(t) = -5t^2 + 20t + 1\). Quand atteint-il sa hauteur maximale, et laquelle ?

Solution

\(h(t) = 1 \iff -5t^2 + 20t = 0 \iff -5t(t - 4) = 0\) : \(t = 0\) ou \(t = 4\). L'axe est \(t = 2\).

\(h(2) = -20 + 40 + 1 = 21\) m. Comme \(a = -5 < 0\), c'est un maximum, atteint à \(t = 2\) s.

3. Racines et signe

Avec la forme factorisée

\(f(x) = a(x - x_1)(x - x_2)\) a pour racines \(x_1\) et \(x_2\) (solutions de \(f(x) = 0\)). \(f(x)\) est du signe de \(a\) à l'extérieur des racines et du signe opposé entre elles.

\(x\)\(-\infty\)\(x_1\)\(x_2\)\(+\infty\)
signe de \(f(x)\) (cas \(a > 0\))\(+\)0\(-\)0\(+\)

Méthode : factoriser avec une racine évidente

Si \(x_1\) est racine de \(ax^2 + bx + c\), on peut écrire \(a(x - x_1)(x - x_2)\) et trouver \(x_2\) en identifiant le produit des racines \(x_1 x_2 = \tfrac{c}{a}\). Ex. : \(x^2 - 5x + 6\), racine évidente \(2\) ; \(2 \times x_2 = 6\), donc \(x_2 = 3\) : \(x^2 - 5x + 6 = (x - 2)(x - 3)\).

Exemple 2

Résoudre \(x^2 = 7\) puis \(-2(x + 1)(x - 3) > 0\).

Solution

\(x^2 = 7 \iff x = \sqrt7\) ou \(x = -\sqrt7\).

\(a = -2 < 0\) : le produit est positif entre les racines : \(S = ]-1\,;\,3[\).

Pour aller plus loin : le discriminant

Hors programme du tronc commun mais indispensable en prépa : pour \(ax^2 + bx + c\), on pose \(\Delta = b^2 - 4ac\). Si \(\Delta > 0\), deux racines \(\dfrac{-b \pm \sqrt\Delta}{2a}\) ; si \(\Delta = 0\), une racine \(-\tfrac{b}{2a}\) ; si \(\Delta < 0\), aucune racine réelle. Voir Calcul algébrique sans faute.

4. Manipuler

Parabole \(y = a(x - x_1)(x - x_2)\)

Déplace les racines et change \(a\) : l'axe reste au milieu des racines, le signe de \(a\) décide du sens.

Entraînement : sommet, image, racines

Valeur exacte ou arrondie à 0,01 près.

Quiz

La parabole de \(f(x) = -3(x - 1)(x + 5)\) a pour axe de symétrie :

  1. \(x = 1\)
  2. \(x = 3\)
  3. \(x = -2\)
  4. \(x = -3\)

Milieu des racines \(1\) et \(-5\) : \(\dfrac{1 + (-5)}{2} = -2\).

\(f(x) = 2x^2 - 8\) est négative sur :

  1. \([-2\,;\,2]\)
  2. \(]-\infty\,;\,-2] \cup [2\,;\,+\infty[\)
  3. \([0\,;\,4]\)
  4. \(\mathbb{R}\)

\(2x^2 - 8 = 2(x - 2)(x + 2)\), \(a > 0\) : négative entre les racines.

\(f(x) = -x^2 + 4\) admet :

  1. un minimum égal à 4
  2. un maximum égal à 0
  3. un minimum égal à 0
  4. un maximum égal à 4

\(a = -1 < 0\) : maximum au sommet \((0\,;\,4)\).

L'équation \(x^2 = -9\) :

  1. a pour solutions \(3\) et \(-3\)
  2. n'a pas de solution réelle
  3. a pour solution \(-3\)
  4. a une infinité de solutions

Un carré est toujours positif ou nul.
