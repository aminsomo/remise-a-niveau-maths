Algorithmique et programmation en Python

Variables, conditions, boucles, fonctions et listes en Python : de quoi calculer les termes d'une suite, chercher un seuil, approcher une solution d'équation ou simuler une expérience aléatoire. À l'examen comme en prépa, on te demandera surtout de lire un programme et de prévoir ce qu'il affiche.

Prérequis : les bases de Python vues en seconde.

1. Variables, types et opérations

Affectation

x = 3 range la valeur 3 dans la variable x (en langage naturel on écrit \(x \leftarrow 3\)). x = x + 1 calcule d'abord x + 1 avec l'ancienne valeur, puis remplace : x vaut maintenant 4. Le signe = de Python n'est donc pas une égalité mathématique, c'est une « mise en mémoire ».

Types et opérateurs

  • Types : entier int (7), flottant float (7.5 — avec un point !), booléen bool (True/False), chaîne str ("bonjour"), liste list.
  • + - * / ; ** pour la puissance (2**3 vaut 8) ; // quotient entier (17 // 5 vaut 3) ; % reste (17 % 5 vaut 2).
  • Fonctions utiles : abs, round, len ; avec from math import sqrt, pi, exp, log : racine, π, exponentielle, ln.

Fonction

def f(x):
    return 3 * x**2 - 2 * x + 1   # return renvoie le résultat

print(f(2))   # 9

Une fonction reçoit des paramètres et renvoie une valeur avec return (à ne pas confondre avec print, qui se contente d'afficher).

Exemple 1 — échange

Que contiennent a et b après a = 5, b = 2, a = a + b, b = a - b, a = a - b ?

Solution

\(a = 7\), puis \(b = 7 - 2 = 5\), puis \(a = 7 - 5 = 2\) : les valeurs ont été échangées (\(a = 2\), \(b = 5\)). En Python, on peut aussi écrire a, b = b, a.

2. Conditions et boucles

Instruction conditionnelle

if x > 0 and x < 10:      # and (ET), or (OU), not (NON)
    print("entre 0 et 10")
elif x == 0:               # == teste l'égalité ; != « différent »
    print("nul")
else:
    print("ailleurs")

L'indentation (le décalage vers la droite) indique ce qui est « à l'intérieur » du if : elle est obligatoire en Python.

Boucles

  • for k in range(n): répète \(n\) fois, \(k\) prenant les valeurs \(0, 1, \dots, n - 1\). range(a, b) va de \(a\) à \(b - 1\) ; range(a, b, p) avance de \(p\) en \(p\).
  • while condition: répète tant que la condition est vraie. On l'utilise quand on ne connaît pas le nombre de tours à l'avance (algorithme de seuil). Attention à la boucle infinie si la condition ne devient jamais fausse !

Exemple 2 — somme et seuil

def somme(n):            # 1 + 2 + ... + n
    s = 0
    for k in range(1, n + 1):
        s = s + k
    return s

def seuil(S):            # premier n tel que 1,05^n > S
    n, u = 0, 1
    while u <= S:
        n, u = n + 1, u * 1.05
    return n

print(somme(10), seuil(2))   # 55 15

3. Listes

Créer et utiliser une liste

  • En extension : L = [2, 3, 5, 7]. En compréhension : carres = [k**2 for k in range(6)] donne [0, 1, 4, 9, 16, 25], avec un filtre : [k for k in range(20) if k % 3 == 0] (les multiples de 3).
  • L[0] est le premier élément (on compte à partir de 0), L[-1] le dernier, len(L) la longueur.
  • L.append(x) ajoute \(x\) à la fin ; sum(L), max(L), min(L) ; for x in L: parcourt les éléments.

4. Algorithmes classiques

Résoudre \(f(x) = 0\) par balayage

def balayage(f, a, pas):
    x = a
    while f(x) * f(x + pas) > 0:   # pas de changement de signe
        x = x + pas
    return x, x + pas              # la solution est entre les deux

print(balayage(lambda x: x**3 - 2, 0, 0.01))   # (1.25..., 1.26...) car ∛2 ≈ 1,2599

Si \(f\) change de signe entre \(x\) et \(x + \text{pas}\), la courbe traverse l'axe entre les deux : on a encadré la solution à « pas » près.

Compter, chercher un maximum

def compter(L, seuil):          # combien de valeurs dépassent le seuil ?
    c = 0
    for x in L:
        if x > seuil:
            c = c + 1
    return c

def maximum(L):
    m = L[0]
    for x in L:
        if x > m:
            m = x
    return m

Exemple 3 — simulation

Écrire une fonction qui simule \(n\) lancers d'un dé et renvoie la fréquence des 6.

Solution 
from random import randint

def freq6(n):
    return len([1 for _ in range(n) if randint(1, 6) == 6]) / n

print(freq6(10000))   # proche de 1/6 ≈ 0,167

Aide-mémoire

6. Manipuler

Balayage pas à pas pour \(x^3 - c = 0\)

Le programme avance de \(x\) en \(x + \text{pas}\) jusqu'au changement de signe. Un pas 10 fois plus petit : un chiffre exact de plus, mais 10 fois plus de tours.

Entraînement : que renvoie ce programme ?

Exécute le programme « à la main » et donne la valeur affichée.

Quiz

Combien de fois s'exécute le corps de for k in range(2, 9): ?

  1. 9
  2. 8
  3. 7
  4. 6

\(k\) va de 2 à 8 inclus : \(9 - 2 = 7\) tours.

[2 * k for k in range(4)] vaut :

  1. [0, 2, 4, 6]
  2. [2, 4, 6, 8]
  3. [0, 1, 2, 3]
  4. [2, 4, 6]

range(4) donne 0, 1, 2, 3.

Pour répéter un calcul jusqu'à dépasser un seuil, on utilise :

  1. un if
  2. une liste
  3. une boucle for de longueur fixe
  4. une boucle while

On ne connaît pas le nombre de tours à l'avance.

Que vaut 7 % 3 en Python ?

  1. 2,33
  2. 1
  3. 2
  4. 21

% donne le reste de la division euclidienne : \(7 = 2 \times 3 + 1\).
