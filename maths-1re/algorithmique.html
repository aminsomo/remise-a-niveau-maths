Algorithmique et programmation en Python

Variables, conditions, boucles, fonctions et listes en Python : de quoi calculer les termes d'une suite, trouver un seuil, approcher une solution par balayage ou simuler une expérience aléatoire.

Prérequis : les bases de Python vues en seconde.

1. Variables, affectation, fonctions

Affectation

x = 3 range la valeur 3 dans la variable x (en langage naturel : \(x \leftarrow 3\)). x = x + 1 remplace l'ancienne valeur par la nouvelle. Types usuels : entier (int), flottant (float), booléen (True/False), chaîne (str), liste (list).

Fonction

def f(x):
    return 3 * x**2 - 2 * x + 1   # ** est la puissance en Python

print(f(2))   # 9

Exemple 1 — échange

Que contiennent a et b après a = 5, b = 2, a = a + b, b = a - b, a = a - b ?

Solution

\(a = 7\), puis \(b = 7 - 2 = 5\), puis \(a = 7 - 5 = 2\) : les valeurs ont été échangées (\(a = 2\), \(b = 5\)).

2. Conditions et boucles

Instruction conditionnelle et opérateurs logiques

if x > 0 and x < 10:      # and (ET), or (OU), not (NON)
    print("entre 0 et 10")
elif x == 0:               # == teste l'égalité, = affecte
    print("nul")
else:
    print("ailleurs")

Boucles

  • for k in range(n): répète \(n\) fois, \(k\) prenant les valeurs \(0, 1, \dots, n - 1\).
  • while condition: répète tant que la condition est vraie (nombre de tours inconnu à l'avance : algorithme de seuil).

Exemple 2 — somme et seuil

def somme(n):            # 1 + 2 + ... + n
    s = 0
    for k in range(1, n + 1):
        s = s + k
    return s

def seuil(S):            # premier n tel que 1,05^n > S
    n, u = 0, 1
    while u <= S:
        n, u = n + 1, u * 1.05
    return n

print(somme(10), seuil(2))   # 55 15

3. Listes et balayage

Listes

Une liste se crée en extension L = [2, 3, 5, 7] ou en compréhension carres = [k**2 for k in range(6)] (→ [0, 1, 4, 9, 16, 25]), éventuellement filtrée : [k for k in range(20) if k % 3 == 0]. L[0] est le premier élément, len(L) la longueur, L.append(x) ajoute \(x\) à la fin.

Résoudre \(f(x) = 0\) par balayage

def balayage(f, a, pas):
    x = a
    while f(x) * f(x + pas) > 0:   # pas de changement de signe
        x = x + pas
    return x, x + pas              # la solution est entre les deux

print(balayage(lambda x: x**3 - 2, 0, 0.01))   # (1.25..., 1.26...) car ∛2 ≈ 1,2599

Exemple 3 — simulation

Écrire une fonction qui simule \(n\) lancers d'un dé et renvoie la fréquence des 6.

Solution 
from random import randint

def freq6(n):
    return len([1 for _ in range(n) if randint(1, 6) == 6]) / n

print(freq6(10000))   # proche de 1/6 ≈ 0,167

Le programme avance de \(x\) en \(x + \text{pas}\) jusqu'au changement de signe. Un pas 10 fois plus petit : un chiffre exact de plus, mais 10 fois plus de tours.

Quiz

Combien de fois s'exécute le corps de for k in range(2, 9): ?

  1. 9
  2. 8
  3. 7
  4. 6

\(k\) va de 2 à 8 inclus : \(9 - 2 = 7\) tours.

[2 * k for k in range(4)] vaut :

  1. [0, 2, 4, 6]
  2. [2, 4, 6, 8]
  3. [0, 1, 2, 3]
  4. [2, 4, 6]

range(4) donne 0, 1, 2, 3.

Pour répéter un calcul jusqu'à dépasser un seuil, on utilise :

  1. un if
  2. une liste
  3. une boucle for de longueur fixe
  4. une boucle while

On ne connaît pas le nombre de tours à l'avance.
