Suites : modèles d'évolutions discrètes

Une suite décrit une grandeur mesurée à intervalles réguliers : un capital chaque année, une population de bactéries chaque heure, la charge d'une batterie à chaque cycle. On apprend à la générer, à la représenter et à reconnaître une croissance linéaire ou exponentielle.

Prérequis : évolutions en pourcentage, fonctions affines.

1. Générer une suite

Définition

Une suite \(u\) associe à chaque entier naturel \(n\) un nombre réel noté \(u(n)\) ou \(u_n\) : le terme de rang \(n\).

  • Relation fonctionnelle : \(u_n = f(n)\), par exemple \(u_n = n^2 + 1\). On calcule directement \(u_{10} = 101\).
  • Relation de récurrence : on donne \(u_0\) et une règle \(u_{n+1} = f(u_n)\). Pour \(u_3\), il faut \(u_1\), puis \(u_2\).

Sens de variation et représentation

\(u\) est croissante si \(u_{n+1} \geq u_n\) pour tout \(n\), décroissante si \(u_{n+1} \leq u_n\). On représente une suite par le nuage de points de coordonnées \((n\,;\,u_n)\) : des points isolés, sans les relier.

Exemple 1 — une suite ni arithmétique ni géométrique

\(u_0 = 1\) et \(u_{n+1} = 2u_n - 3\). Calculer \(u_1, u_2, u_3\).

Solution

\(u_1 = 2 \times 1 - 3 = -1\), \(u_2 = 2 \times (-1) - 3 = -5\), \(u_3 = -13\). Les écarts \(-2, -4, -8\) ne sont pas constants et les quotients non plus : elle n'est ni arithmétique ni géométrique.

2. Suites arithmétiques : croissance linéaire

Définition

\(u\) est arithmétique de raison \(r\) si, pour tout \(n\), \(u_{n+1} = u_n + r\) : on ajoute toujours la même quantité. C'est le modèle d'une évolution absolue constante.

Propriétés

  • Croissante si \(r > 0\), décroissante si \(r < 0\), constante si \(r = 0\).
  • Les points \((n\,;\,u_n)\) sont alignés. Terme de rang \(n\) : \(u_n = u_0 + nr\).

Méthode : démontrer qu'une suite est arithmétique

On calcule \(u_{n+1} - u_n\) pour un \(n\) quelconque et on montre que le résultat ne dépend pas de \(n\). Ex. \(u_n = 5 - 3n\) : \(u_{n+1} - u_n = 5 - 3(n+1) - 5 + 3n = -3\). Arithmétique de raison \(-3\).

3. Suites géométriques : croissance exponentielle

Définition

\(u\) (à termes strictement positifs) est géométrique de raison \(q > 0\) si \(u_{n+1} = q \times u_n\) : on multiplie toujours par le même nombre. C'est le modèle d'une évolution relative constante : \(+t\,\%\) par période donne \(q = 1 + \tfrac{t}{100}\).

Propriétés (\(u_0 > 0\))

  • Croissante si \(q > 1\), décroissante si \(0 < q < 1\), constante si \(q = 1\).
  • Terme de rang \(n\) : \(u_n = u_0 \times q^n\) (formule étudiée en détail en Terminale).

Méthode : démontrer qu'une suite est géométrique

On montre que \(\dfrac{u_{n+1}}{u_n}\) est constant. Ex. \(u_n = 3 \times 2^n\) : \(\dfrac{u_{n+1}}{u_n} = \dfrac{3 \times 2^{n+1}}{3 \times 2^n} = 2\).

Exemple 2 — deux offres d'abonnement

Offre A : 600 € la 1re année puis +40 € par an. Offre B : 600 € puis +6 % par an. Laquelle est la moins chère la 5e année ?

Solution

A est arithmétique : \(a_4 = 600 + 4 \times 40 = 760\) €. B est géométrique : \(b_4 = 600 \times 1{,}06^4 \approx 757{,}49\) €.

B est encore un peu moins chère la 5e année, mais la croissance exponentielle finit toujours par dépasser la linéaire : dès la 6e année, \(b_5 \approx 802{,}94 > a_5 = 800\).

4. Algorithme de seuil

Pour trouver le premier rang où une suite dépasse un seuil, on calcule les termes un par un avec une boucle while :

def seuil(u0, S):
    n, u = 0, u0
    while u <= S:
        u = 2 * u - 3      # relation de récurrence
        n = n + 1
    return n

print(seuil(4, 1000))   # 10 : u_10 = 1 027 est le premier terme > 1 000

Exemple 3

Une colonie de 500 bactéries augmente de 20 % par heure. Au bout de combien d'heures dépasse-t-elle 2 000 ?

Solution

\(u_{n+1} = 1{,}2\,u_n\) : 500 ; 600 ; 720 ; 864 ; 1 036,8 ; 1 244,2 ; 1 493 ; 1 791,6 ; 2 149,9. Il faut 8 heures.

5. Manipuler

Suite définie par \(u_{n+1} = a\,u_n + b\)

Avec \(a = 1\) elle est arithmétique, avec \(b = 0\) géométrique. Ailleurs, elle n'est ni l'une ni l'autre : observe le nuage de points.

6. En prépa

Ce qui t'attend

La suite \(u_{n+1} = a u_n + b\) (arithmético-géométrique) est un grand classique : on cherche le point fixe \(\ell = a\ell + b\) puis on montre que \(u_n - \ell\) est géométrique. Les suites récurrentes \(u_{n+1} = f(u_n)\) sont étudiées dès le premier trimestre. Voir Suites (Terminale) et Sommes et récurrence.
