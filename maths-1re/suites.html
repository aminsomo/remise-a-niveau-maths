Suites : modèles d'évolutions discrètes

Une suite, c'est une liste de nombres qui décrit une grandeur mesurée à intervalles réguliers : un capital chaque année, une population de bactéries chaque heure, la charge d'une batterie à chaque cycle. Tu vas apprendre à fabriquer une suite, à la dessiner, et à reconnaître deux grands modèles : la croissance linéaire et la croissance exponentielle.

Prérequis : évolutions en pourcentage, fonctions affines.

1. Qu'est-ce qu'une suite ?

Définition

Une suite \(u\) associe à chaque entier naturel \(n\) (0, 1, 2, 3…) un nombre réel, noté \(u(n)\) ou \(u_n\). \(n\) est le rang (la « position ») et \(u_n\) le terme de rang \(n\). Attention : \(u_{n+1}\) est le terme suivant \(u_n\), alors que \(u_n + 1\) est \(u_n\) augmenté de 1.

Deux façons de fabriquer une suite

  • Par une formule en fonction de \(n\) (relation fonctionnelle) : \(u_n = f(n)\), par exemple \(u_n = n^2 + 1\). On calcule directement n'importe quel terme : \(u_{10} = 101\).
  • Par récurrence : on donne le premier terme et une règle pour passer d'un terme au suivant, \(u_{n+1} = f(u_n)\). Par exemple \(u_0 = 5\) et \(u_{n+1} = 2u_n - 3\). Pour connaître \(u_3\), il faut d'abord calculer \(u_1\), puis \(u_2\).

Sens de variation

\(u\) est croissante si chaque terme est plus grand que le précédent : \(u_{n+1} \geq u_n\) pour tout \(n\). Elle est décroissante si \(u_{n+1} \leq u_n\) pour tout \(n\). Elle est constante si tous ses termes sont égaux. Pour le savoir, on étudie le signe de la différence \(u_{n+1} - u_n\).

Représentation graphique

On représente une suite par le nuage de points de coordonnées \((n\,;\,u_n)\). Ce sont des points isolés : on ne les relie pas, car la suite n'existe que pour des entiers.

Exemple 1 — une suite ni arithmétique ni géométrique

\(u_0 = 1\) et \(u_{n+1} = 2u_n - 3\). Calculer \(u_1, u_2, u_3\).

Solution

\(u_1 = 2 \times 1 - 3 = -1\), \(u_2 = 2 \times (-1) - 3 = -5\), \(u_3 = -13\). Les écarts (\(-2, -4, -8\)) ne sont pas constants, les quotients non plus : ce n'est ni une suite arithmétique ni une suite géométrique.

2. Suites arithmétiques : croissance linéaire

Définition

\(u\) est arithmétique de raison \(r\) si on passe d'un terme au suivant en ajoutant toujours le même nombre \(r\) : \[u_{n+1} = u_n + r.\] C'est le modèle d'une évolution absolue constante : « +40 € par an », « −3 cm par jour ».

Propriétés

  • Terme de rang \(n\) : \(u_n = u_0 + n\,r\). Plus généralement, pour deux rangs \(n\) et \(p\) : \(u_n = u_p + (n - p)\,r\).
  • Sens de variation : croissante si \(r > 0\), décroissante si \(r < 0\), constante si \(r = 0\).
  • Les points \((n\,;\,u_n)\) sont alignés : c'est une croissance (ou décroissance) linéaire.
  • Somme de termes consécutifs : \(S = \text{nombre de termes} \times \dfrac{\text{premier} + \text{dernier}}{2}\). En particulier \(1 + 2 + \dots + n = \dfrac{n(n+1)}{2}\).

Méthode : montrer qu'une suite est arithmétique

On calcule \(u_{n+1} - u_n\) et on vérifie que le résultat ne dépend pas de \(n\) : c'est la raison. Ex. : \(u_n = 5 - 3n\) donne \(u_{n+1} - u_n = 5 - 3(n+1) - 5 + 3n = -3\). La suite est arithmétique de raison \(-3\).

3. Suites géométriques : croissance exponentielle

Définition

\(u\) (à termes strictement positifs) est géométrique de raison \(q > 0\) si on passe d'un terme au suivant en multipliant toujours par le même nombre \(q\) : \[u_{n+1} = q \times u_n.\] C'est le modèle d'une évolution relative constante : une hausse de \(t\,\%\) par période donne \(q = 1 + \dfrac{t}{100}\), une baisse de \(t\,\%\) donne \(q = 1 - \dfrac{t}{100}\).

Propriétés (\(u_0 > 0\))

  • Terme de rang \(n\) : \(u_n = u_0 \times q^n\), et \(u_n = u_p \times q^{\,n-p}\) (formule détaillée en Terminale).
  • Sens de variation : croissante si \(q > 1\), décroissante si \(0 < q < 1\), constante si \(q = 1\).
  • Somme : pour \(q \neq 1\), \(1 + q + q^2 + \dots + q^n = \dfrac{1 - q^{n+1}}{1 - q}\).
  • Les points \((n\,;\,u_n)\) ne sont pas alignés : la croissance s'accélère (on parle de croissance exponentielle).

Méthode : montrer qu'une suite est géométrique

On calcule \(\dfrac{u_{n+1}}{u_n}\) et on vérifie que le résultat ne dépend pas de \(n\). Ex. : \(u_n = 3 \times 2^n\) donne \(\dfrac{u_{n+1}}{u_n} = \dfrac{3 \times 2^{n+1}}{3 \times 2^n} = 2\) : géométrique de raison 2.

Exemple 2 — deux offres d'abonnement

Offre A : 600 € la 1re année puis +40 € par an. Offre B : 600 € puis +6 % par an. Laquelle est la moins chère la 5e année ?

Solution

A est arithmétique : \(a_4 = 600 + 4 \times 40 = 760\) €. B est géométrique : \(b_4 = 600 \times 1{,}06^4 \approx 757{,}49\) €.

B est encore un peu moins chère la 5e année, mais la croissance exponentielle finit toujours par dépasser la croissance linéaire : dès la 6e année, \(b_5 \approx 802{,}94 > a_5 = 800\).

4. Algorithme de seuil

Pour trouver le premier rang à partir duquel une suite dépasse une valeur (un « seuil »), on calcule les termes un par un avec une boucle while (« tant que ») :

def seuil(u0, S):
    n, u = 0, u0
    while u <= S:          # tant que le seuil n'est pas dépassé
        u = 2 * u - 3      # on calcule le terme suivant
        n = n + 1          # et on avance d'un rang
    return n

print(seuil(4, 1000))   # 10 : u_10 = 1 027 est le premier terme > 1 000

Exemple 3

Une colonie de 500 bactéries augmente de 20 % par heure. Au bout de combien d'heures dépasse-t-elle 2 000 ?

Solution

\(u_{n+1} = 1{,}2\,u_n\) : 500 ; 600 ; 720 ; 864 ; 1 036,8 ; 1 244,2 ; 1 493 ; 1 791,6 ; 2 149,9. Il faut 8 heures.

6. Manipuler

Suite définie par \(u_{n+1} = a\,u_n + b\)

Avec \(a = 1\) elle est arithmétique, avec \(b = 0\) géométrique. Ailleurs, elle n'est ni l'une ni l'autre : observe le nuage de points.

7. En prépa

Ce qui t'attend

La suite \(u_{n+1} = a u_n + b\) (arithmético-géométrique) est un grand classique : on cherche le point fixe \(\ell = a\ell + b\) puis on montre que \(u_n - \ell\) est géométrique. Les suites récurrentes \(u_{n+1} = f(u_n)\) sont étudiées dès le premier trimestre. Voir Suites (Terminale) et Sommes et récurrence.
