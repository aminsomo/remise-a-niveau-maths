Nombres complexes

Les nombres complexes permettent de calculer très simplement avec des grandeurs sinusoïdales : en électricité, une impédance est un nombre complexe, et on additionne des tensions déphasées comme on additionne des vecteurs. En Terminale, on ajoute la forme exponentielle, la plus pratique pour multiplier.

Prérequis : complexes de 1re, trigonométrie, exponentielle.

1. Forme algébrique

Rappels

\(i^2 = -1\) (en électricité on note \(j\)). Tout complexe s'écrit \(z = a + ib\), \(a = \mathrm{Re}(z)\), \(b = \mathrm{Im}(z)\). On calcule comme avec des réels en remplaçant \(i^2\) par \(-1\). Conjugué : \(\bar z = a - ib\), et \(z\bar z = a^2 + b^2\). Pour un quotient, on multiplie haut et bas par le conjugué du dénominateur.

Équations du second degré à coefficients réels

Pour \(az^2 + bz + c = 0\) avec \(\Delta = b^2 - 4ac < 0\), il y a deux solutions complexes conjuguées : \[z_1 = \frac{-b - i\sqrt{-\Delta}}{2a}, \qquad z_2 = \frac{-b + i\sqrt{-\Delta}}{2a}.\] (Si \(\Delta \geq 0\), on retrouve les solutions réelles habituelles.)

Exemple 1

Résoudre \(z^2 + 2z + 5 = 0\).

Solution

\(\Delta = 4 - 20 = -16\), \(\sqrt{-\Delta} = 4\) : \(z = \dfrac{-2 \pm 4i}{2}\), soit \(z_1 = -1 - 2i\) et \(z_2 = -1 + 2i\).

2. Module, argument, forme trigonométrique

Définitions

Dans le plan complexe, \(z = a + ib\) est l'affixe de \(M(a\,;\,b)\). Le module \(|z| = \sqrt{a^2 + b^2} = OM\) ; un argument \(\theta = \arg z\) est l'angle entre l'axe réel et \(\overrightarrow{OM}\) (à \(2\pi\) près). Forme trigonométrique : \(z = r(\cos\theta + i\sin\theta)\) avec \(r = |z|\), \(\cos\theta = \dfrac ar\), \(\sin\theta = \dfrac br\).

Règles

  • \(|zz'| = |z||z'|\), \(\left|\dfrac{z}{z'}\right| = \dfrac{|z|}{|z'|}\), \(|z^n| = |z|^n\), \(|\bar z| = |z|\).
  • \(\arg(zz') = \arg z + \arg z'\), \(\arg\dfrac{z}{z'} = \arg z - \arg z'\), \(\arg(z^n) = n\arg z\), \(\arg\bar z = -\arg z\) (à \(2\pi\) près).
  • Géométrie : \(AB = |z_B - z_A|\) ; l'angle \((\overrightarrow{AB}, \overrightarrow{AC})\) vaut \(\arg\dfrac{z_C - z_A}{z_B - z_A}\).

3. Forme exponentielle

Notation d'Euler

On pose \(e^{i\theta} = \cos\theta + i\sin\theta\). Tout complexe non nul s'écrit alors \[z = r\,e^{i\theta} \qquad (r = |z| > 0,\ \theta = \arg z).\] Valeurs à connaître : \(e^{i0} = 1\), \(e^{i\pi/2} = i\), \(e^{i\pi} = -1\), \(e^{-i\pi/2} = -i\).

Pourquoi c'est pratique

  • Multiplier : \(r e^{i\theta} \times r' e^{i\theta'} = rr'\,e^{i(\theta + \theta')}\) (on multiplie les modules, on additionne les arguments).
  • Diviser : \(\dfrac{re^{i\theta}}{r'e^{i\theta'}} = \dfrac{r}{r'}e^{i(\theta - \theta')}\) ; conjugué : \(\overline{re^{i\theta}} = re^{-i\theta}\).
  • Puissance (formule de Moivre) : \((re^{i\theta})^n = r^ne^{in\theta}\).
  • Formules d'Euler : \(\cos\theta = \dfrac{e^{i\theta} + e^{-i\theta}}{2}\), \(\sin\theta = \dfrac{e^{i\theta} - e^{-i\theta}}{2i}\).

Exemple 2

\(z = 1 + i\). Forme exponentielle, puis calcul de \(z^8\).

Solution

\(|z| = \sqrt2\), \(\arg z = \dfrac{\pi}{4}\) : \(z = \sqrt2\,e^{i\pi/4}\).

\(z^8 = (\sqrt2)^8 e^{i8\pi/4} = 16\,e^{2i\pi} = 16\).

4. Application : impédances complexes

Représentation complexe d'un signal

À la tension \(u(t) = U\sqrt2\cos(\omega t + \varphi)\) on associe le complexe \(\underline U = U e^{j\varphi}\) (module = valeur efficace, argument = phase). Dériver revient à multiplier par \(j\omega\).

Impédances

  • Loi d'Ohm complexe : \(\underline U = \underline Z\,\underline I\).
  • Résistance : \(\underline Z_R = R\) ; bobine : \(\underline Z_L = jL\omega\) ; condensateur : \(\underline Z_C = \dfrac{1}{jC\omega} = -\dfrac{j}{C\omega}\).
  • En série, les impédances s'ajoutent ; en parallèle, les inverses s'ajoutent : \(\dfrac{1}{\underline Z} = \dfrac{1}{\underline Z_1} + \dfrac{1}{\underline Z_2}\).
  • \(|\underline Z| = \dfrac{U}{I}\) (rapport des valeurs efficaces) et \(\arg\underline Z = \varphi_u - \varphi_i\) (déphasage de la tension sur le courant).
  • RLC série : \(\underline Z = R + j\left(L\omega - \dfrac{1}{C\omega}\right)\) ; résonance quand \(L\omega = \dfrac{1}{C\omega}\), soit \(f_0 = \dfrac{1}{2\pi\sqrt{LC}}\) : \(\underline Z = R\), le courant est maximal.

Exemple 3

Une résistance de 30 Ω en série avec une bobine de 0,127 H, sous 230 V et 50 Hz. Impédance, intensité efficace, déphasage ?

Solution

\(L\omega = 0{,}127 \times 100\pi \approx 40\) Ω : \(\underline Z = 30 + 40j\), \(|\underline Z| = 50\) Ω, \(I = \dfrac{230}{50} = 4{,}6\) A.

\(\varphi = \arctan\dfrac{40}{30} \approx 53^\circ\) : la tension est en avance sur le courant (circuit inductif).

5. L'essentiel à retenir

Formulaire

  • \(z = a + ib = r(\cos\theta + i\sin\theta) = re^{i\theta}\), \(r = \sqrt{a^2 + b^2}\).
  • \(re^{i\theta} \cdot r'e^{i\theta'} = rr'e^{i(\theta + \theta')}\) ; \((re^{i\theta})^n = r^ne^{in\theta}\) ; \(e^{i\pi} = -1\).
  • \(\Delta < 0\) : \(z = \dfrac{-b \pm i\sqrt{-\Delta}}{2a}\).
  • \(\underline Z_R = R\), \(\underline Z_L = jL\omega\), \(\underline Z_C = \dfrac{1}{jC\omega}\) ; \(\underline U = \underline Z\,\underline I\) ; résonance \(f_0 = \dfrac{1}{2\pi\sqrt{LC}}\).

6. Manipuler

Le plan complexe : produit = rotation + homothétie

Fais glisser \(z_1\) (rose) avec la souris ou le doigt. Le produit \(z_1 z_2\) a pour module \(|z_1||z_2|\) et pour argument \(\arg z_1 + \arg z_2\).

Impédance d'un circuit R, L, C série

Fais varier la fréquence : le vecteur \(\underline{Z}\) tourne. À la résonance \(L\omega = \dfrac{1}{C\omega}\), \(\underline{Z} = R\) est réel.

Entraînement : module et argument

Argument en degrés, dans \(]-180\,;180]\) ; module à 0,01 près.

7. En prépa

Ce qui t'attend

  • Formules d'Euler \(\cos\theta = \dfrac{e^{i\theta} + e^{-i\theta}}{2}\) et de Moivre, pour linéariser \(\cos^3 x\) ou exprimer \(\cos 3x\).
  • Racines \(n\)-ièmes de l'unité, résolution de \(z^n = a\), équations de degré 2 à coefficients complexes.
  • Notation complexe systématique en électrocinétique et en ondes (TSI) : filtres, diagrammes de Bode.
