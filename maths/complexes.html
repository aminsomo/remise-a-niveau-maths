Nombres complexes

Un nombre complexe, c'est un point (ou un vecteur) du plan sur lequel on sait calculer. Les trois écritures — algébrique, trigonométrique, exponentielle — servent à additionner, multiplier, et décrire les grandeurs sinusoïdales en électricité.

Prérequis : trigonométrie (cercle trigonométrique, valeurs remarquables).

1. Forme algébrique

Définition

On admet l'existence d'un nombre \(i\) tel que \(i^2 = -1\). Un nombre complexe s'écrit de façon unique \[z = a + ib, \qquad a, b \in \mathbb{R}.\] \(a = \text{Re}(z)\) est la partie réelle, \(b = \text{Im}(z)\) la partie imaginaire. L'ensemble des complexes est noté \(\mathbb{C}\). On note \(j\) au lieu de \(i\) en électricité (pour ne pas confondre avec l'intensité).

Calculs

  • On calcule comme avec des polynômes en \(i\), en remplaçant \(i^2\) par \(-1\).
  • Conjugué : \(\bar z = a - ib\). On a \(z\bar z = a^2 + b^2\) (réel positif).
  • Pour diviser, on multiplie numérateur et dénominateur par le conjugué du dénominateur.

Exemple 1

Avec \(z_1 = 2 + 3i\) et \(z_2 = 1 - i\), calculer \(z_1 z_2\) et \(\dfrac{z_1}{z_2}\).

Solution

\(z_1z_2 = 2 - 2i + 3i - 3i^2 = 2 + i + 3 = 5 + i\).

\(\dfrac{z_1}{z_2} = \dfrac{(2+3i)(1+i)}{(1-i)(1+i)} = \dfrac{2 + 2i + 3i - 3}{1 + 1} = -\dfrac12 + \dfrac52 i\).

Équation du second degré à coefficients réels

\(az^2 + bz + c = 0\) avec \(\Delta = b^2 - 4ac < 0\) a deux solutions complexes conjuguées : \[z = \frac{-b \pm i\sqrt{-\Delta}}{2a}.\]

2. Module, argument, forme trigonométrique

Définitions

Le point \(M(a\,;b)\) est l'image de \(z = a + ib\) dans le plan complexe.

  • Module : \(|z| = \sqrt{a^2 + b^2} = OM\) (une longueur).
  • Argument : \(\arg z = \theta\) (à \(2\pi\) près), angle orienté entre l'axe des réels et \(\overrightarrow{OM}\), avec \(\cos\theta = \dfrac{a}{|z|}\) et \(\sin\theta = \dfrac{b}{|z|}\).
  • Forme trigonométrique : \(z = r(\cos\theta + i\sin\theta)\) avec \(r = |z|\).

Exemple 2

Écrire \(z = 1 + i\sqrt3\) sous forme trigonométrique.

Solution

\(|z| = \sqrt{1 + 3} = 2\). \(\cos\theta = \tfrac12\), \(\sin\theta = \tfrac{\sqrt3}{2}\) donc \(\theta = \dfrac{\pi}{3}\). \(z = 2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)\).

3. Forme exponentielle

Notation d'Euler

On pose \(e^{i\theta} = \cos\theta + i\sin\theta\). Tout complexe non nul s'écrit \(z = r\,e^{i\theta}\).

Règles (comme les puissances)

\[r e^{i\theta} \times r' e^{i\theta'} = rr'\,e^{i(\theta + \theta')} \qquad \frac{re^{i\theta}}{r'e^{i\theta'}} = \frac{r}{r'}e^{i(\theta-\theta')} \qquad \left(re^{i\theta}\right)^n = r^n e^{in\theta}\]

Multiplier : on multiplie les modules et on ajoute les arguments. Multiplier par \(e^{i\alpha}\) = tourner de \(\alpha\) autour de \(O\).

Exemple 3 — puissance

Calculer \((1 + i)^{8}\).

Solution

\(1 + i = \sqrt2\,e^{i\pi/4}\) donc \((1+i)^8 = (\sqrt2)^8 e^{i\,8\pi/4} = 16\,e^{2i\pi} = 16\).

4. Application : impédances complexes

En régime sinusoïdal, une tension \(u(t) = U\sqrt2\cos(\omega t + \varphi)\) est représentée par le complexe \(\underline{U} = U e^{j\varphi}\). Chaque dipôle a une impédance complexe \(\underline{Z}\) avec \(\underline{U} = \underline{Z}\,\underline{I}\) :

Dipôle\(\underline{Z}\)moduledéphasage \(u\) / \(i\)
Résistance \(R\)\(R\)\(R\)\(0\)
Bobine \(L\)\(jL\omega\)\(L\omega\)\(+\pi/2\) (u en avance)
Condensateur \(C\)\(\dfrac{1}{jC\omega} = -\dfrac{j}{C\omega}\)\(\dfrac{1}{C\omega}\)\(-\pi/2\) (u en retard)

En série, les impédances s'additionnent : \(\underline{Z} = R + jL\omega\). Le module \(|\underline{Z}|\) donne le rapport des valeurs efficaces \(U/I\), l'argument donne le déphasage \(\varphi\), et \(\cos\varphi\) est le facteur de puissance.

Exemple 4 — moteur modélisé par R-L série

\(R = 30\ \Omega\), \(L = 0{,}127\) H, sous 230 V / 50 Hz. Calculer \(\underline{Z}\), \(I\) et \(\cos\varphi\).

Solution

\(L\omega = 0{,}127 \times 2\pi \times 50 \approx 40\ \Omega\). \(\underline{Z} = 30 + 40j\), \(|\underline{Z}| = 50\ \Omega\).

\(I = 230 / 50 = 4{,}6\) A ; \(\cos\varphi = 30 / 50 = 0{,}6\) ; \(\varphi = \arctan(40/30) \approx 53°\).

5. Manipuler

Le plan complexe : produit = rotation + homothétie

Fais glisser \(z_1\) (rose) avec la souris ou le doigt. Le produit \(z_1 z_2\) a pour module \(|z_1||z_2|\) et pour argument \(\arg z_1 + \arg z_2\).

Impédance d'un circuit R, L, C série

Fais varier la fréquence : le vecteur \(\underline{Z}\) tourne. À la résonance \(L\omega = \dfrac{1}{C\omega}\), \(\underline{Z} = R\) est réel.

Entraînement : module et argument

Argument en degrés, dans \(]-180\,;180]\) ; module à 0,01 près.

6. En prépa

Ce qui t'attend

  • Formules d'Euler \(\cos\theta = \dfrac{e^{i\theta} + e^{-i\theta}}{2}\) et de Moivre, pour linéariser \(\cos^3 x\) ou exprimer \(\cos 3x\).
  • Racines \(n\)-ièmes de l'unité, résolution de \(z^n = a\), équations de degré 2 à coefficients complexes.
  • Notation complexe systématique en électrocinétique et en ondes (TSI) : filtres, diagrammes de Bode.
