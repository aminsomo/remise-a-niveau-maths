Suites numériques

Reconnaître une suite arithmétique ou géométrique, calculer n'importe quel terme ou une somme de termes, et comprendre ce qui se passe « à l'infini » (la limite). C'est la porte d'entrée de toute l'analyse en prépa.

Prérequis : calcul avec les puissances, équations du premier degré, suites de 1re.

1. Qu'est-ce qu'une suite ?

Définition

Une suite numérique \((u_n)\) associe à chaque entier naturel \(n\) un nombre réel \(u_n\), le terme de rang \(n\). On peut la voir comme une fonction définie seulement sur les entiers : \(n \mapsto u_n\).

  • Forme explicite : \(u_n = f(n)\). On calcule directement n'importe quel terme. Ex. : \(u_n = 3n^2 - 1\), donc \(u_{10} = 299\).
  • Par récurrence : on donne le premier terme et une relation \(u_{n+1} = f(u_n)\). Pour obtenir \(u_{10}\), il faut calculer tous les termes précédents. Ex. : \(u_0 = 2\) et \(u_{n+1} = 0{,}5\,u_n + 3\).

Sens de variation

\((u_n)\) est croissante si, pour tout \(n\), \(u_{n+1} \geq u_n\), c'est-à-dire \(u_{n+1} - u_n \geq 0\). Elle est décroissante si \(u_{n+1} - u_n \leq 0\) pour tout \(n\). Une suite est majorée par \(M\) si \(u_n \leq M\) pour tout \(n\), minorée par \(m\) si \(u_n \geq m\), bornée si elle est les deux.

Méthode : étudier le sens de variation

On calcule \(u_{n+1} - u_n\) et on étudie son signe. Si tous les termes sont strictement positifs, on peut aussi comparer \(\dfrac{u_{n+1}}{u_n}\) à 1. Si \(u_n = f(n)\), on peut étudier les variations de \(f\) sur \([0\,;\,+\infty[\).

Exemple 1

Étudier le sens de variation de \(u_n = n^2 - 4n\).

Solution

\(u_{n+1} - u_n = (n+1)^2 - 4(n+1) - n^2 + 4n = 2n + 1 - 4 = 2n - 3.\)

Pour \(n \geq 2\), \(2n - 3 > 0\) : la suite est croissante à partir du rang 2 (elle décroît de \(u_0 = 0\) à \(u_2 = -4\)).

2. Suites arithmétiques

Définition

\((u_n)\) est arithmétique de raison \(r\) si on passe d'un terme au suivant en ajoutant toujours le même nombre : \(u_{n+1} = u_n + r\).

Propriétés

  • Terme général : \(u_n = u_0 + n\,r\), et plus généralement \(u_n = u_p + (n - p)\,r\).
  • Sens de variation : croissante si \(r > 0\), décroissante si \(r < 0\), constante si \(r = 0\).
  • Limite : \(+\infty\) si \(r > 0\), \(-\infty\) si \(r < 0\).
  • Somme de termes consécutifs : \(S = \text{(nombre de termes)} \times \dfrac{\text{premier} + \text{dernier}}{2}\) ; en particulier \(1 + 2 + \dots + n = \dfrac{n(n+1)}{2}\).

Exemple 2 — tarif d'abonnement

Un loyer vaut 600 € la première année et augmente de 15 € chaque année. Quel loyer la 10e année ? Combien a-t-on payé au total sur 10 ans ?

Solution

On pose \(u_1 = 600\) et \(r = 15\). Alors \(u_{10} = u_1 + 9r = 600 + 135 = 735\) €.

Somme : \(S = 10 \times \dfrac{600 + 735}{2} = 6\,675\) €.

3. Suites géométriques

Définition

\((u_n)\) est géométrique de raison \(q\) si on passe d'un terme au suivant en multipliant toujours par le même nombre : \(u_{n+1} = q \times u_n\).

Propriétés

  • Terme général : \(u_n = u_0 \times q^n\), et \(u_n = u_p \times q^{\,n-p}\).
  • Si \(u_0 > 0\) : croissante si \(q > 1\), décroissante si \(0 < q < 1\) ; si \(q < 0\), les termes changent de signe à chaque rang.
  • Somme (pour \(q \neq 1\)) :
\[1 + q + q^2 + \dots + q^n = \frac{1 - q^{n+1}}{1 - q} \qquad\qquad S = \text{premier terme} \times \frac{1 - q^{\text{nombre de termes}}}{1 - q}\]

Méthode : évolution en pourcentage

Augmenter de \(t\,\%\) revient à multiplier par \(1 + \dfrac{t}{100}\) ; diminuer de \(t\,\%\) revient à multiplier par \(1 - \dfrac{t}{100}\). Une évolution d'un pourcentage constant donne donc une suite géométrique.

Exemple 3 — usure d'une batterie

Une batterie perd 3 % de sa capacité à chaque cycle d'usure de 100 charges. Neuve, elle stocke 50 Wh. Capacité après 8 de ces cycles ?

Solution

\(C_n = 50 \times 0{,}97^n\) donc \(C_8 = 50 \times 0{,}97^8 \approx 39{,}2\) Wh.

Exemple 4 — somme géométrique

Calculer \(S = 2 + 6 + 18 + \dots + 2 \times 3^{9}\).

Solution

Suite géométrique de premier terme 2 et de raison 3, avec 10 termes (exposants 0 à 9) : \(S = 2 \times \dfrac{1 - 3^{10}}{1 - 3} = 3^{10} - 1 = 59\,048.\)

4. Limites et algorithme de seuil

Ce que veut dire « tendre vers »

\((u_n)\) tend vers \(+\infty\) si ses termes finissent par dépasser n'importe quel nombre, aussi grand soit-il. Elle converge vers \(\ell\) si ses termes finissent par être aussi proches de \(\ell\) qu'on veut. On note \(\lim\limits_{n \to +\infty} u_n = \ell\). Une suite qui ne converge pas est dite divergente.

Limite de \(q^n\)

  • Si \(q > 1\) : \(\lim\limits_{n\to+\infty} q^n = +\infty\).
  • Si \(-1 < q < 1\) : \(\lim\limits_{n\to+\infty} q^n = 0\).
  • Si \(q = 1\) : \(q^n = 1\) ; si \(q \leq -1\) : pas de limite (les termes oscillent).

Conséquence : pour \(-1 < q < 1\), \(1 + q + q^2 + \dots + q^n \to \dfrac{1}{1-q}\).

Opérations et théorèmes

  • Les limites s'ajoutent, se multiplient et se divisent comme on s'y attend, sauf dans les formes indéterminées : \(\infty - \infty\), \(0 \times \infty\), \(\dfrac{\infty}{\infty}\), \(\dfrac00\) (il faut alors transformer l'expression, souvent en factorisant le terme le plus fort).
  • Comparaison : si \(u_n \geq v_n\) et \(v_n \to +\infty\), alors \(u_n \to +\infty\). Gendarmes : si \(v_n \leq u_n \leq w_n\) et \(v_n, w_n \to \ell\), alors \(u_n \to \ell\).
  • Une suite croissante et majorée converge ; une suite décroissante et minorée converge (théorème admis en Terminale).

Pour trouver le premier rang à partir duquel \(u_n\) dépasse un seuil, on programme une boucle while :

def seuil(u0, q, S):
    n, u = 0, u0
    while u < S:        # tant que le seuil n'est pas atteint
        n = n + 1
        u = q * u
    return n

print(seuil(50, 1.04, 100))   # 18 : la valeur double en 18 ans à +4 %/an

On peut aussi résoudre \(u_0 q^n \geq S\) avec le logarithme (voir le chapitre Logarithmes).

5. L'essentiel à retenir

Formulaire

  • Arithmétique : \(u_n = u_0 + nr\), somme = nb de termes × (premier + dernier)/2, \(1 + \dots + n = \dfrac{n(n+1)}{2}\).
  • Géométrique : \(u_n = u_0q^n\), \(1 + q + \dots + q^n = \dfrac{1 - q^{n+1}}{1 - q}\) ; \(+t\,\%\) ⇔ \(\times(1 + t/100)\).
  • \(q^n \to +\infty\) si \(q > 1\), \(\to 0\) si \(|q| < 1\) ; formes indéterminées : \(\infty - \infty\), \(0 \times \infty\), \(\infty/\infty\), \(0/0\).
  • Croissante + majorée ⇒ convergente ; gendarmes ; seuil : boucle while ou logarithme.

7. En prépa

Ce qui t'attend

  • Les suites arithmético-géométriques \(u_{n+1} = a u_n + b\) : on cherche le point fixe \(\ell = a\ell + b\), puis \(v_n = u_n - \ell\) est géométrique de raison \(a\).
  • Les démonstrations par récurrence (voir Sommes et récurrence).
  • La définition rigoureuse de la limite avec \(\varepsilon\), les suites adjacentes, les suites récurrentes \(u_{n+1} = f(u_n)\).

Exemple 5 — arithmético-géométrique (niveau prépa)

\(u_0 = 10\) et \(u_{n+1} = 0{,}5\,u_n + 3\). Exprimer \(u_n\) en fonction de \(n\) et donner sa limite.

Solution

Point fixe : \(\ell = 0{,}5\ell + 3 \iff \ell = 6\). Posons \(v_n = u_n - 6\) : \(v_{n+1} = 0{,}5u_n + 3 - 6 = 0{,}5(u_n - 6) = 0{,}5\,v_n\).

Donc \(v_n = v_0 \times 0{,}5^n = 4 \times 0{,}5^n\) et \(u_n = 6 + 4 \times 0{,}5^n \to 6\) car \(0 < 0{,}5 < 1\).

Quiz

\((u_n)\) est arithmétique avec \(u_3 = 7\) et \(u_8 = 22\). Sa raison vaut :

  1. \(5\)
  2. \(3\)
  3. \(15\)
  4. \(22/7\)

\(u_8 = u_3 + 5r\) donc \(5r = 15\) et \(r = 3\).

Un prix augmente de 5 % par an. Le prix \(p_n\) après \(n\) années vérifie :

  1. \(p_{n+1} = p_n + 0{,}05\)
  2. \(p_{n+1} = 0{,}05\,p_n\)
  3. \(p_{n+1} = 1{,}05\,p_n\)
  4. \(p_{n+1} = p_n + 5\)

Augmenter de 5 % revient à multiplier par \(1 + 0{,}05 = 1{,}05\) : suite géométrique.

\(\lim\limits_{n\to+\infty} 3 \times 0{,}8^n =\)

  1. \(0\)
  2. \(3\)
  3. \(+\infty\)
  4. pas de limite

\(-1 < 0{,}8 < 1\) donc \(0{,}8^n \to 0\), et \(3 \times 0 = 0\).

\(1 + 2 + 3 + \dots + 100 =\)

  1. \(10\,000\)
  2. \(5\,000\)
  3. \(10\,100\)
  4. \(5\,050\)

\(\dfrac{100 \times 101}{2} = 5\,050\) (100 termes, moyenne du premier et du dernier = 50,5).

Combien de termes dans la somme \(u_5 + u_6 + \dots + u_{20}\) ?

  1. 15
  2. 16
  3. 20
  4. 21

De 5 à 20 inclus : \(20 - 5 + 1 = 16\) termes. Erreur classique : oublier le « +1 ».
