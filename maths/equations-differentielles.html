Équations différentielles

Une équation différentielle relie une fonction inconnue à sa dérivée : « la vitesse de refroidissement est proportionnelle à l'écart de température », « l'accélération est proportionnelle au déplacement ». La résoudre, c'est trouver toutes les fonctions qui obéissent à cette loi. Elles sont partout en physique (circuits RC, ressorts, chute avec frottements).

Prérequis : exponentielle, cos et sin, dérivation.

1. L'équation \(y' = ay\)

Vocabulaire

Une solution de l'équation différentielle \(y' = ay\) (avec \(a\) un réel donné) est une fonction \(y\), dérivable, telle que \(y'(t) = a\,y(t)\) pour tout \(t\). Une condition initiale comme \(y(0) = y_0\) permet de choisir une seule solution parmi toutes.

Théorème

Les solutions de \(y' = ay\) sont les fonctions \(y(t) = C\,e^{at}\), où \(C\) est une constante réelle. Avec \(y(0) = y_0\), on obtient \(C = y_0\) : \(y(t) = y_0\,e^{at}\). Si \(a < 0\), les solutions tendent vers 0 (décroissance exponentielle) ; si \(a > 0\), elles « explosent ».

Exemple 1 — radioactivité

Le nombre de noyaux vérifie \(N' = -\lambda N\) avec \(\lambda = 0{,}1\ \mathrm{an^{-1}}\) et \(N(0) = 10^6\). Combien reste-t-il de noyaux après 10 ans ? Demi-vie ?

Solution

\(N(t) = 10^6 e^{-0{,}1t}\), donc \(N(10) = 10^6 e^{-1} \approx 3{,}7 \times 10^5\).

Demi-vie : \(e^{-0{,}1 t} = \tfrac12 \iff t = \dfrac{\ln 2}{0{,}1} \approx 6{,}9\) ans.

2. L'équation \(y' = ay + b\)

Théorème (\(a \neq 0\))

Les solutions de \(y' = ay + b\) sont les fonctions \[y(t) = C\,e^{at} - \frac{b}{a}.\] La fonction constante \(y_p = -\dfrac{b}{a}\) est une solution particulière (on la trouve en posant \(y' = 0\)) ; on lui ajoute les solutions de \(y' = ay\). Si \(a < 0\), toutes les solutions tendent vers \(y_p\) : c'est le régime permanent ; la partie \(Ce^{at}\) est le régime transitoire, de constante de temps \(\tau = -\dfrac1a\).

Méthode

  1. Mettre l'équation sous la forme \(y' = ay + b\) (diviser si nécessaire).
  2. Solution particulière constante \(y_p = -b/a\).
  3. Solution générale \(y(t) = Ce^{at} + y_p\).
  4. Utiliser la condition initiale pour trouver \(C\).

Exemple 2 — charge d'un condensateur

Dans un circuit RC alimenté par une tension \(E\), \(RC\,u_C' + u_C = E\) avec \(u_C(0) = 0\). Exprimer \(u_C(t)\).

Solution

On écrit \(u_C' = -\dfrac{1}{RC}u_C + \dfrac{E}{RC}\) : \(a = -\dfrac{1}{RC}\), \(y_p = E\). Donc \(u_C(t) = Ce^{-t/RC} + E\), et \(u_C(0) = 0\) donne \(C = -E\).

\(u_C(t) = E\left(1 - e^{-t/RC}\right)\), avec la constante de temps \(\tau = RC\) : 63 % de \(E\) à \(t = \tau\).

Exemple 3 — refroidissement

Un café à 80 °C refroidit dans une pièce à 20 °C selon \(\theta' = -0{,}05(\theta - 20)\) (\(t\) en min). Température après 20 min ?

Solution

\(\theta' = -0{,}05\theta + 1\) : \(y_p = 20\), donc \(\theta(t) = Ce^{-0{,}05t} + 20\) ; \(\theta(0) = 80\) donne \(C = 60\).

\(\theta(20) = 60e^{-1} + 20 \approx 42\) °C.

3. L'équation \(y'' + \omega^2 y = 0\)

Théorème (\(\omega > 0\))

Les solutions de \(y'' + \omega^2 y = 0\) (où \(y''\) est la dérivée de \(y'\)) sont les fonctions \[y(t) = A\cos(\omega t) + B\sin(\omega t) \qquad\text{que l'on peut aussi écrire}\qquad y(t) = Y_m\cos(\omega t + \varphi),\] avec \(Y_m = \sqrt{A^2 + B^2}\) l'amplitude. Ce sont des oscillations sinusoïdales de période \(T = \dfrac{2\pi}{\omega}\), qui ne s'amortissent pas. Deux conditions initiales (position \(y(0)\) et vitesse \(y'(0)\)) donnent \(A = y(0)\) et \(B = \dfrac{y'(0)}{\omega}\).

En physique

  • Masse \(m\) au bout d'un ressort de raideur \(k\), sans frottement : \(x'' + \dfrac{k}{m}x = 0\), donc \(\omega = \sqrt{\dfrac{k}{m}}\) et \(T = 2\pi\sqrt{\dfrac{m}{k}}\).
  • Circuit LC : \(u'' + \dfrac{1}{LC}u = 0\), donc \(\omega = \dfrac{1}{\sqrt{LC}}\).
  • Pendule simple (petites oscillations) : \(\theta'' + \dfrac{g}{\ell}\theta = 0\).

Exemple 4

Résoudre \(y'' + 4y = 0\) avec \(y(0) = 3\) et \(y'(0) = 2\).

Solution

\(\omega = 2\) : \(y(t) = A\cos 2t + B\sin 2t\). \(y(0) = A = 3\) ; \(y'(t) = -2A\sin 2t + 2B\cos 2t\), donc \(y'(0) = 2B = 2\) et \(B = 1\).

\(y(t) = 3\cos 2t + \sin 2t\), d'amplitude \(\sqrt{10} \approx 3{,}16\) et de période \(\pi\).

4. L'essentiel à retenir

Formulaire

  • \(y' = ay\) : \(y = Ce^{at}\) ; avec \(y(0) = y_0\) : \(y = y_0e^{at}\).
  • \(y' = ay + b\) : \(y = Ce^{at} - \dfrac ba\) ; régime permanent \(-b/a\) si \(a < 0\), \(\tau = -1/a\).
  • \(y'' + \omega^2y = 0\) : \(y = A\cos\omega t + B\sin\omega t = Y_m\cos(\omega t + \varphi)\), \(A = y(0)\), \(B = y'(0)/\omega\).
  • RC : \(\tau = RC\) ; ressort : \(\omega = \sqrt{k/m}\) ; LC : \(\omega = 1/\sqrt{LC}\).

6. En prépa

Ce qui t'attend

  • \(y' + a(t)y = b(t)\) avec coefficients variables : \(y = Ce^{-A(t)} + y_p\) où \(A\) est une primitive de \(a\) ; variation de la constante.
  • \(ay'' + by' + cy = 0\) : équation caractéristique \(ar^2 + br + c = 0\), avec racines complexes → oscillations amorties (circuit RLC, ressort avec frottement).
  • Second membre sinusoïdal → notation complexe, résonance (lien avec nombres complexes).

Quiz

Les solutions de \(y' = 3y\) sont :

  1. \(y = 3e^{t}\)
  2. \(y = Ce^{t/3}\)
  3. \(y = Ce^{3t}\)
  4. \(y = e^{3t} + C\)

\(y' = ay \Rightarrow y = Ce^{at}\). Attention : \(e^{3t} + C\) n'est pas solution (sa dérivée est \(3e^{3t}\), pas \(3(e^{3t}+C)\)).

La solution constante de \(y' = -2y + 8\) est :

  1. \(4\)
  2. \(-4\)
  3. \(8\)
  4. \(-16\)

\(0 = -2y + 8 \Rightarrow y = 4\). C'est la valeur limite (régime permanent).

\(y'' + 9y = 0\). La période des solutions est :

  1. \(9\)
  2. \(2\pi/9\)
  3. \(3\)
  4. \(2\pi/3\)

\(\omega^2 = 9 \Rightarrow \omega = 3\) et \(T = 2\pi/\omega\).

Pour \(\tau u' + u = E\), la constante de temps est :

  1. \(E\)
  2. \(\tau\)
  3. \(1/\tau\)
  4. \(E/\tau\)

Solution : \(u = E + Ce^{-t/\tau}\).

Quelle fonction est solution de \(y'' + 4y = 0\) avec \(y(0) = 0\) et \(y'(0) = 2\) ?

  1. \(2\cos 2t\)
  2. \(2\sin 2t\)
  3. \(\sin 2t\)
  4. \(\cos 2t\)

\(A = y(0) = 0\), \(B = y'(0)/\omega = 2/2 = 1\).
