Équations différentielles

Une équation dont l'inconnue est une fonction, reliée à ses dérivées. C'est le langage de la physique : circuit RC, refroidissement, chute avec frottements, oscillateurs. En STI2D : \(y' = ay\), \(y' = ay + b\) et \(y'' + \omega^2 y = 0\).

Prérequis : exponentielle, dérivation, fonctions cos et sin.

1. L'équation \(y' = ay\)

Théorème

Les solutions sur \(\mathbb{R}\) de \(y' = ay\) (\(a\) réel) sont les fonctions \[y(t) = C\,e^{at}, \qquad C \in \mathbb{R}.\] Avec une condition initiale \(y(0) = y_0\), il y a une seule solution : \(y(t) = y_0\,e^{at}\).

Exemple 1 — décharge d'un condensateur

Dans un circuit RC en décharge, \(RC\,\dfrac{\mathrm{d}u}{\mathrm{d}t} + u = 0\), avec \(u(0) = 10\) V, \(R = 10\ \text{k}\Omega\), \(C = 100\ \mu\text{F}\). Trouver \(u(t)\).

Solution

On réécrit : \(u' = -\dfrac{1}{RC}u\), forme \(y' = ay\) avec \(a = -\dfrac{1}{RC} = -\dfrac{1}{1} = -1\ \text{s}^{-1}\) (\(\tau = RC = 1\) s).

\(u(t) = 10\,e^{-t}\) (en volts, \(t\) en secondes).

2. L'équation \(y' = ay + b\)

Théorème (\(a \neq 0\))

Les solutions de \(y' = ay + b\) sont \[y(t) = C\,e^{at} - \frac{b}{a}, \qquad C \in \mathbb{R}.\] La fonction constante \(y_p = -\dfrac{b}{a}\) est une solution particulière (on la trouve en posant \(y' = 0\)) ; \(C\,e^{at}\) est la solution générale de l'équation homogène \(y' = ay\).

Méthode en 3 temps

  1. Mettre l'équation sous la forme \(y' = ay + b\) (ou \(\tau y' + y = K\)).
  2. Écrire \(y(t) = Ce^{at} + y_p\) avec \(y_p\) constante.
  3. Déterminer \(C\) avec la condition initiale.

Exemple 2 — loi de refroidissement

Un café à 80 °C refroidit dans une pièce à 20 °C : \(\theta'(t) = -0{,}1\,\big(\theta(t) - 20\big)\), \(t\) en minutes. Trouver \(\theta(t)\) et le temps pour atteindre 40 °C.

Solution

\(\theta' = -0{,}1\,\theta + 2\) : \(a = -0{,}1\), \(b = 2\), \(y_p = -\dfrac{2}{-0{,}1} = 20\) (la température de la pièce !).

\(\theta(t) = Ce^{-0{,}1t} + 20\) et \(\theta(0) = 80 \Rightarrow C = 60\). Donc \(\theta(t) = 60e^{-0{,}1t} + 20\).

\(\theta(t) = 40 \iff e^{-0{,}1t} = \tfrac13 \iff t = 10\ln 3 \approx 11\) min.

Exemple 3 — charge d'un condensateur

\(RC\,u' + u = E\), \(u(0) = 0\). Montrer que \(u(t) = E\big(1 - e^{-t/RC}\big)\).

Solution

\(u' = -\dfrac{1}{RC}u + \dfrac{E}{RC}\) ; \(y_p = E\) ; \(u(t) = Ce^{-t/RC} + E\) ; \(u(0) = 0 \Rightarrow C = -E\).

3. L'équation \(y'' + \omega^2 y = 0\)

Théorème (\(\omega > 0\))

Les solutions sont les fonctions \[y(t) = A\cos(\omega t) + B\sin(\omega t), \qquad A, B \in \mathbb{R},\] qu'on peut aussi écrire \(y(t) = Y_m\cos(\omega t + \varphi)\). Elles sont périodiques de période \(T = \dfrac{2\pi}{\omega}\). Deux conditions initiales (\(y(0)\) et \(y'(0)\)) déterminent \(A\) et \(B\) : \(A = y(0)\), \(B = \dfrac{y'(0)}{\omega}\).

Exemple 4 — ressort horizontal sans frottement

\(m\,x'' = -k\,x\) avec \(m = 0{,}2\) kg, \(k = 20\) N/m, \(x(0) = 3\) cm, \(x'(0) = 0\). Trouver \(x(t)\) et la période.

Solution

\(x'' + \dfrac{k}{m}x = 0\) avec \(\omega^2 = 100\), \(\omega = 10\) rad/s. \(x(t) = A\cos 10t + B\sin 10t\) ; \(A = 3\), \(B = 0\). Donc \(x(t) = 3\cos(10t)\) cm et \(T = \dfrac{2\pi}{10} \approx 0{,}63\) s.

4. Manipuler

\(y' = ay + b\) : toutes les solutions convergent ?

Chaque courbe correspond à une condition initiale \(y(0)\) différente. Si \(a < 0\), toutes tendent vers \(-b/a\) (régime permanent). Si \(a > 0\), elles divergent. Clique sur le graphique pour ajouter ta propre condition initiale.

Oscillateur \(y'' + \omega^2 y = 0\)

Règle \(y(0)\), \(y'(0)\) et \(\omega\). Observe l'amplitude \(Y_m = \sqrt{A^2 + B^2}\) et la période \(2\pi/\omega\).

Entraînement

Donne la valeur demandée (à 0,01 près).

5. En prépa

Ce qui t'attend

  • \(y' + a(t)y = b(t)\) avec coefficients variables : \(y = Ce^{-A(t)} + y_p\) où \(A\) est une primitive de \(a\) ; variation de la constante.
  • \(ay'' + by' + cy = 0\) : équation caractéristique \(ar^2 + br + c = 0\), avec racines complexes → oscillations amorties (circuit RLC, ressort avec frottement).
  • Second membre sinusoïdal → notation complexe, résonance (lien avec le chapitre « Nombres complexes »).

Quiz

Les solutions de \(y' = 3y\) sont :

  1. \(y = 3e^{t}\)
  2. \(y = Ce^{t/3}\)
  3. \(y = Ce^{3t}\)
  4. \(y = e^{3t} + C\)

\(y' = ay \Rightarrow y = Ce^{at}\). Attention : \(e^{3t} + C\) n'est pas solution (sa dérivée est \(3e^{3t}\), pas \(3(e^{3t}+C)\)).

La solution constante de \(y' = -2y + 8\) est :

  1. \(4\)
  2. \(-4\)
  3. \(8\)
  4. \(-16\)

\(0 = -2y + 8 \Rightarrow y = 4\). C'est la valeur limite (régime permanent).

\(y'' + 9y = 0\). La période des solutions est :

  1. \(9\)
  2. \(2\pi/9\)
  3. \(3\)
  4. \(2\pi/3\)

\(\omega^2 = 9 \Rightarrow \omega = 3\) et \(T = 2\pi/\omega\).

Pour \(\tau u' + u = E\), la constante de temps est :

  1. \(E\)
  2. \(\tau\)
  3. \(1/\tau\)
  4. \(E/\tau\)

Solution : \(u = E + Ce^{-t/\tau}\).

Quelle fonction est solution de \(y'' + 4y = 0\) avec \(y(0) = 0\) et \(y'(0) = 2\) ?

  1. \(2\cos 2t\)
  2. \(2\sin 2t\)
  3. \(\sin 2t\)
  4. \(\cos 2t\)

\(A = y(0) = 0\), \(B = y'(0)/\omega = 2/2 = 1\).
