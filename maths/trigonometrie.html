Trigonométrie et signaux sinusoïdaux

Radians, cercle trigonométrique, valeurs remarquables, fonctions cos et sin, et le modèle \(A\cos(\omega t + \varphi)\) qui décrit le courant alternatif, les ondes et les oscillations.

Prérequis : théorème de Pythagore, trigonométrie du triangle rectangle (SOH-CAH-TOA).

1. Radians et cercle trigonométrique

Radian

Sur le cercle de rayon 1, un angle de \(\theta\) radians intercepte un arc de longueur \(\theta\). Un tour complet vaut \(2\pi\) rad. Conversion : \(\theta_{\text{rad}} = \theta_{\text{deg}} \times \dfrac{\pi}{180}\).

Cosinus et sinus d'un réel

Le point \(M\) du cercle trigonométrique associé à \(\theta\) a pour coordonnées \((\cos\theta\,;\sin\theta)\). Donc :

\[\cos^2\theta + \sin^2\theta = 1, \qquad -1 \leq \cos\theta \leq 1, \qquad -1 \leq \sin\theta \leq 1.\]
\(\theta\)\(0\)\(\pi/6\)\(\pi/4\)\(\pi/3\)\(\pi/2\)\(\pi\)
\(\cos\theta\)\(1\)\(\frac{\sqrt3}{2}\)\(\frac{\sqrt2}{2}\)\(\frac12\)\(0\)\(-1\)
\(\sin\theta\)\(0\)\(\frac12\)\(\frac{\sqrt2}{2}\)\(\frac{\sqrt3}{2}\)\(1\)\(0\)

Angles associés (à retrouver sur le cercle, pas à apprendre par cœur)

\(\cos(-\theta) = \cos\theta\), \(\sin(-\theta) = -\sin\theta\), \(\cos(\pi - \theta) = -\cos\theta\), \(\sin(\pi - \theta) = \sin\theta\), \(\cos(\theta + \pi) = -\cos\theta\), \(\cos\left(\tfrac{\pi}{2} - \theta\right) = \sin\theta\).

Exemple 1

Calculer \(\cos\dfrac{5\pi}{6}\) et \(\sin\left(-\dfrac{3\pi}{4}\right)\).

Solution

\(\dfrac{5\pi}{6} = \pi - \dfrac{\pi}{6}\) donc \(\cos\dfrac{5\pi}{6} = -\cos\dfrac{\pi}{6} = -\dfrac{\sqrt3}{2}\).

\(-\dfrac{3\pi}{4}\) est dans le 3e quadrant : \(\sin\left(-\dfrac{3\pi}{4}\right) = -\dfrac{\sqrt2}{2}\).

2. Formules d'addition et équations

Formules d'addition et de duplication

\[\cos(a+b) = \cos a\cos b - \sin a\sin b \qquad \sin(a+b) = \sin a\cos b + \cos a\sin b\] \[\cos 2a = \cos^2 a - \sin^2 a = 2\cos^2 a - 1 = 1 - 2\sin^2 a \qquad \sin 2a = 2\sin a\cos a\]

Astuce : elles se retrouvent instantanément avec \(e^{i(a+b)} = e^{ia}e^{ib}\) (voir complexes).

Équations

  • \(\cos x = \cos a \iff x = a + 2k\pi\) ou \(x = -a + 2k\pi\) (\(k \in \mathbb{Z}\)).
  • \(\sin x = \sin a \iff x = a + 2k\pi\) ou \(x = \pi - a + 2k\pi\).

Exemple 2

Résoudre \(2\cos x = 1\) sur \(]-\pi\,;\pi]\).

Solution

\(\cos x = \tfrac12 = \cos\tfrac{\pi}{3}\). Sur \(]-\pi\,;\pi]\) : \(S = \left\{-\tfrac{\pi}{3}\,;\tfrac{\pi}{3}\right\}\).

3. Fonctions sinusoïdales

Fonctions cos et sin

  • Définies sur \(\mathbb{R}\), périodiques de période \(2\pi\).
  • \(\cos\) est paire (courbe symétrique par rapport à l'axe des ordonnées), \(\sin\) est impaire (symétrique par rapport à l'origine).
  • \(\cos' = -\sin\) et \(\sin' = \cos\).

Signal sinusoïdal

\[s(t) = A\cos(\omega t + \varphi)\]
  • \(A > 0\) : amplitude (valeur maximale) ; valeur efficace \(A/\sqrt2\).
  • \(\omega\) : pulsation (rad/s), avec \(\omega = 2\pi f = \dfrac{2\pi}{T}\) ; \(f\) fréquence (Hz), \(T\) période (s).
  • \(\varphi\) : phase à l'origine (rad). Le décalage temporel entre deux signaux de même fréquence vaut \(\Delta t = \dfrac{\Delta\varphi}{\omega}\).

Exemple 3 — secteur EDF

Le secteur délivre 230 V efficaces à 50 Hz. Écrire \(u(t)\) sachant que \(u(0) = 0\) et \(u\) croissante en 0.

Solution

\(A = 230\sqrt2 \approx 325\) V, \(\omega = 2\pi \times 50 = 100\pi \approx 314\) rad/s, \(T = 20\) ms.

\(u(t) = 325\sin(100\pi t) = 325\cos\left(100\pi t - \tfrac{\pi}{2}\right)\).

4. Manipuler

Du cercle à la sinusoïde

Fais tourner \(\theta\) : l'abscisse de \(M\) donne \(\cos\theta\) (bleu), l'ordonnée donne \(\sin\theta\) (rose). À droite, on « déroule » le sinus.

Signal \(A\cos(\omega t + \varphi)\)

Compare au signal de référence (gris) \(\cos t\). Observe l'effet de chaque paramètre séparément.

Entraînement : valeurs remarquables

Réponds en valeur exacte (sqrt(3)/2, -1/2…) ou décimale à 0,01 près.

5. En prépa

Ce qui t'attend

  • La fonction \(\tan\), et les fonctions réciproques \(\arccos\), \(\arcsin\), \(\arctan\).
  • Transformer \(a\cos\omega t + b\sin\omega t\) en \(R\cos(\omega t - \varphi)\) avec \(R = \sqrt{a^2 + b^2}\) : indispensable en physique.
  • Formules \(\cos p + \cos q = 2\cos\frac{p+q}{2}\cos\frac{p-q}{2}\) (battements) et linéarisation.

Quiz

\(120°\) en radians vaut :

  1. \(\pi/3\)
  2. \(3\pi/2\)
  3. \(2\pi/3\)
  4. \(120\pi\)

\(120 \times \dfrac{\pi}{180} = \dfrac{2\pi}{3}\).

Si \(\cos\theta = 0{,}6\) et \(\theta \in [0\,;\pi]\), alors \(\sin\theta =\)

  1. \(0{,}8\)
  2. \(-0{,}8\)
  3. \(0{,}4\)
  4. \(0{,}64\)

\(\sin^2\theta = 1 - 0{,}36 = 0{,}64\), et \(\sin\theta \geq 0\) sur \([0\,;\pi]\).

Un signal \(s(t) = 5\cos(200\pi t)\) a une fréquence de :

  1. 200 Hz
  2. \(200\pi\) Hz
  3. 5 Hz
  4. 100 Hz

\(\omega = 2\pi f = 200\pi \Rightarrow f = 100\) Hz.

\(\sin\left(x + \dfrac{\pi}{2}\right) =\)

  1. \(\sin x\)
  2. \(\cos x\)
  3. \(-\cos x\)
  4. \(-\sin x\)

Formule d'addition : \(\sin x\cos\frac{\pi}{2} + \cos x\sin\frac{\pi}{2} = \cos x\).

Deux signaux à 50 Hz sont déphasés de \(\pi/2\). Leur décalage temporel est :

  1. 2 ms
  2. 10 ms
  3. 5 ms
  4. 0,25 s

\(\pi/2\) = un quart de période ; \(T = 20\) ms, donc 5 ms.
