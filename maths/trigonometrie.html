Trigonométrie et signaux sinusoïdaux

Radians, cercle trigonométrique, formules d'addition et signaux sinusoïdaux \(A\cos(\omega t + \varphi)\) : c'est le langage de l'électricité alternative, des ondes et des vibrations. Ce chapitre reprend la 1re et ajoute les formules qui servent en Terminale et en prépa.

Prérequis : trigonométrie de 1re.

1. Radians et cercle trigonométrique

Rappels

Sur le cercle trigonométrique (centre \(O\), rayon 1, sens direct = sens inverse des aiguilles d'une montre), le réel \(x\) correspond à un point \(M\) ; \(\cos x\) est l'abscisse de \(M\) et \(\sin x\) son ordonnée. \(\pi\) rad \(= 180^\circ\) ; \(x\) et \(x + 2k\pi\) donnent le même point. Pour tout \(x\) : \(\cos^2 x + \sin^2 x = 1\), et \(\tan x = \dfrac{\sin x}{\cos x}\) quand \(\cos x \neq 0\).

\(x\)\(0\)\(\frac{\pi}{6}\)\(\frac{\pi}{4}\)\(\frac{\pi}{3}\)\(\frac{\pi}{2}\)\(\pi\)
\(\cos x\)\(1\)\(\frac{\sqrt3}{2}\)\(\frac{\sqrt2}{2}\)\(\frac12\)\(0\)\(-1\)
\(\sin x\)\(0\)\(\frac12\)\(\frac{\sqrt2}{2}\)\(\frac{\sqrt3}{2}\)\(1\)\(0\)

Angles associés

\(\cos(-x) = \cos x\), \(\sin(-x) = -\sin x\) ; \(\cos(\pi - x) = -\cos x\), \(\sin(\pi - x) = \sin x\) ; \(\cos(\pi + x) = -\cos x\), \(\sin(\pi + x) = -\sin x\) ; \(\cos(\tfrac{\pi}{2} - x) = \sin x\), \(\sin(\tfrac{\pi}{2} - x) = \cos x\). Tout se retrouve en dessinant le cercle.

2. Formules d'addition et équations

Formules d'addition

\[\cos(a + b) = \cos a\cos b - \sin a\sin b \qquad\qquad \sin(a + b) = \sin a\cos b + \cos a\sin b\] \[\cos(a - b) = \cos a\cos b + \sin a\sin b \qquad\qquad \sin(a - b) = \sin a\cos b - \cos a\sin b\]

Formules de duplication (cas \(a = b\))

\[\cos 2a = \cos^2 a - \sin^2 a = 2\cos^2 a - 1 = 1 - 2\sin^2 a \qquad \sin 2a = 2\sin a\cos a\]

D'où aussi \(\cos^2 a = \dfrac{1 + \cos 2a}{2}\) et \(\sin^2 a = \dfrac{1 - \cos 2a}{2}\) (utile pour calculer des valeurs efficaces et des intégrales).

Résoudre une équation trigonométrique

  • \(\cos x = \cos\alpha \iff x = \alpha + 2k\pi\) ou \(x = -\alpha + 2k\pi\) (\(k\) entier).
  • \(\sin x = \sin\alpha \iff x = \alpha + 2k\pi\) ou \(x = \pi - \alpha + 2k\pi\).
  • On cherche d'abord un \(\alpha\) connu (tableau des valeurs), puis on garde les solutions dans l'intervalle demandé.

Exemple 1

Calculer \(\cos\dfrac{\pi}{12}\) en écrivant \(\dfrac{\pi}{12} = \dfrac{\pi}{3} - \dfrac{\pi}{4}\), puis résoudre \(\sin x = \dfrac12\) sur \([0\,;\,2\pi[\).

Solution

\(\cos\dfrac{\pi}{12} = \cos\dfrac{\pi}{3}\cos\dfrac{\pi}{4} + \sin\dfrac{\pi}{3}\sin\dfrac{\pi}{4} = \dfrac12\cdot\dfrac{\sqrt2}{2} + \dfrac{\sqrt3}{2}\cdot\dfrac{\sqrt2}{2} = \dfrac{\sqrt2 + \sqrt6}{4} \approx 0{,}966\).

\(\sin x = \sin\dfrac{\pi}{6}\) : \(x = \dfrac{\pi}{6}\) ou \(x = \pi - \dfrac{\pi}{6} = \dfrac{5\pi}{6}\).

3. Fonctions sinusoïdales

Les fonctions cos et sin

Périodiques de période \(2\pi\), comprises entre −1 et 1 ; \(\cos\) est paire, \(\sin\) est impaire ; \(\cos' = -\sin\) et \(\sin' = \cos\). \(\sin x = \cos\left(x - \tfrac{\pi}{2}\right)\) : la sinusoïde est la cosinusoïde décalée d'un quart de période.

Signal sinusoïdal \(s(t) = A\cos(\omega t + \varphi)\)

  • \(A > 0\) : amplitude ; \(\omega\) : pulsation (rad/s) ; \(\varphi\) : phase à l'origine ; \(\omega t + \varphi\) : phase instantanée.
  • Période \(T = \dfrac{2\pi}{\omega}\), fréquence \(f = \dfrac1T\), donc \(\omega = 2\pi f\).
  • Valeur moyenne nulle ; valeur efficace \(\dfrac{A}{\sqrt2}\).
  • Deux signaux de même pulsation, de phases \(\varphi_1\) et \(\varphi_2\), sont déphasés de \(\Delta\varphi = \varphi_2 - \varphi_1\). Sur un oscillogramme, un décalage \(\Delta t\) correspond à \(|\Delta\varphi| = 2\pi\dfrac{\Delta t}{T}\). Si \(\Delta\varphi = 0\) : en phase ; \(\pi\) : en opposition ; \(\tfrac{\pi}{2}\) : en quadrature.

Somme de deux sinusoïdes de même pulsation

\(a\cos(\omega t) + b\sin(\omega t) = A\cos(\omega t + \varphi)\) avec \(A = \sqrt{a^2 + b^2}\), \(\cos\varphi = \dfrac aA\), \(\sin\varphi = -\dfrac bA\) (formule d'addition). On peut aussi représenter chaque signal par un vecteur tournant (vecteur de Fresnel) ou par un nombre complexe : additionner les signaux revient à additionner les vecteurs.

Exemple 2

Sur un oscillogramme, deux tensions de période 20 ms sont décalées de 5 ms. Déphasage ?

Solution

\(|\Delta\varphi| = 2\pi \times \dfrac{5}{20} = \dfrac{\pi}{2}\) rad : les tensions sont en quadrature.

4. L'essentiel à retenir

Formulaire

  • \(\cos^2 + \sin^2 = 1\) ; angles associés ; valeurs remarquables.
  • \(\cos(a \pm b) = \cos a\cos b \mp \sin a\sin b\), \(\sin(a \pm b) = \sin a\cos b \pm \cos a\sin b\).
  • \(\cos 2a = 2\cos^2 a - 1 = 1 - 2\sin^2 a\), \(\sin 2a = 2\sin a\cos a\).
  • \(\cos x = \cos\alpha \iff x = \pm\alpha + 2k\pi\) ; \(\sin x = \sin\alpha \iff x = \alpha + 2k\pi\) ou \(\pi - \alpha + 2k\pi\).
  • \(A\cos(\omega t + \varphi)\) : \(T = 2\pi/\omega\), \(\omega = 2\pi f\), efficace \(A/\sqrt2\), déphasage \(2\pi\Delta t/T\).

5. Manipuler

Du cercle à la sinusoïde

Fais tourner \(\theta\) : l'abscisse de \(M\) donne \(\cos\theta\) (bleu), l'ordonnée donne \(\sin\theta\) (rose). À droite, on « déroule » le sinus.

Signal \(A\cos(\omega t + \varphi)\)

Compare au signal de référence (gris) \(\cos t\). Observe l'effet de chaque paramètre séparément.

Entraînement : valeurs remarquables

Réponds en valeur exacte (sqrt(3)/2, -1/2…) ou décimale à 0,01 près.

6. En prépa

Ce qui t'attend

  • La fonction \(\tan\), et les fonctions réciproques \(\arccos\), \(\arcsin\), \(\arctan\).
  • Transformer \(a\cos\omega t + b\sin\omega t\) en \(R\cos(\omega t - \varphi)\) avec \(R = \sqrt{a^2 + b^2}\) : indispensable en physique.
  • Formules \(\cos p + \cos q = 2\cos\frac{p+q}{2}\cos\frac{p-q}{2}\) (battements) et linéarisation.

Quiz

\(120°\) en radians vaut :

  1. \(\pi/3\)
  2. \(3\pi/2\)
  3. \(2\pi/3\)
  4. \(120\pi\)

\(120 \times \dfrac{\pi}{180} = \dfrac{2\pi}{3}\).

Si \(\cos\theta = 0{,}6\) et \(\theta \in [0\,;\pi]\), alors \(\sin\theta =\)

  1. \(0{,}8\)
  2. \(-0{,}8\)
  3. \(0{,}4\)
  4. \(0{,}64\)

\(\sin^2\theta = 1 - 0{,}36 = 0{,}64\), et \(\sin\theta \geq 0\) sur \([0\,;\pi]\).

Un signal \(s(t) = 5\cos(200\pi t)\) a une fréquence de :

  1. 200 Hz
  2. \(200\pi\) Hz
  3. 5 Hz
  4. 100 Hz

\(\omega = 2\pi f = 200\pi \Rightarrow f = 100\) Hz.

\(\sin\left(x + \dfrac{\pi}{2}\right) =\)

  1. \(\sin x\)
  2. \(\cos x\)
  3. \(-\cos x\)
  4. \(-\sin x\)

Formule d'addition : \(\sin x\cos\frac{\pi}{2} + \cos x\sin\frac{\pi}{2} = \cos x\).

Deux signaux à 50 Hz sont déphasés de \(\pi/2\). Leur décalage temporel est :

  1. 2 ms
  2. 10 ms
  3. 5 ms
  4. 0,25 s

\(\pi/2\) = un quart de période ; \(T = 20\) ms, donc 5 ms.
