Probabilités et loi binomiale

Contrôle qualité, fiabilité d'un système, tests de dépistage : on modélise le hasard avec des arbres, des variables aléatoires et surtout la loi binomiale, qui compte le nombre de succès quand on répète une même expérience.

Prérequis : probabilités de 1re, variables aléatoires de 1re.

1. Probabilités conditionnelles

Rappels

  • \(P(\bar A) = 1 - P(A)\) ; \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\).
  • Probabilité de B sachant A (si \(P(A) \neq 0\)) : \(P_A(B) = \dfrac{P(A \cap B)}{P(A)}\), d'où \(P(A \cap B) = P(A)P_A(B)\).
  • A et B indépendants \(\iff P(A \cap B) = P(A)P(B) \iff P_A(B) = P(B)\).

Arbres et probabilités totales

Dans un arbre pondéré : les branches issues d'un même nœud ont des probabilités de somme 1 ; la probabilité d'un chemin est le produit des probabilités de ses branches ; la probabilité d'un événement est la somme des chemins qui y mènent. Si \(A_1, \dots, A_n\) partagent l'univers (une partition) : \[P(B) = P(A_1)P_{A_1}(B) + \dots + P(A_n)P_{A_n}(B).\]

Exemple 1 — deux fournisseurs

60 % des pièces viennent du fournisseur A (2 % défectueuses), 40 % de B (5 % défectueuses). Probabilité qu'une pièce soit défectueuse ? Qu'elle vienne de B sachant qu'elle est défectueuse ?

Solution

\(P(D) = 0{,}6 \times 0{,}02 + 0{,}4 \times 0{,}05 = 0{,}012 + 0{,}02 = 0{,}032\).

\(P_D(B) = \dfrac{0{,}02}{0{,}032} = 0{,}625\).

2. Variables aléatoires

Loi, espérance, variance

Une variable aléatoire \(X\) prend les valeurs \(x_1, \dots, x_n\) avec les probabilités \(p_i = P(X = x_i)\) (somme 1). Alors :

  • espérance (valeur moyenne à long terme) : \(E(X) = \sum x_i p_i\) ;
  • variance (dispersion) : \(V(X) = \sum p_i\,(x_i - E(X))^2 = E(X^2) - E(X)^2\) ; écart-type \(\sigma(X) = \sqrt{V(X)}\) ;
  • \(E(aX + b) = aE(X) + b\) et \(V(aX + b) = a^2V(X)\).

3. Loi binomiale

Schéma de Bernoulli et loi binomiale

On répète \(n\) fois, de façon identique et indépendante, une épreuve à deux issues (succès de probabilité \(p\), échec \(1 - p\)). Le nombre \(X\) de succès suit la loi binomiale \(\mathcal B(n, p)\) : \[P(X = k) = \binom{n}{k} p^k (1 - p)^{n-k}, \qquad k = 0, 1, \dots, n.\] Le coefficient binomial \(\binom{n}{k}\) (« k parmi n ») est le nombre de chemins de l'arbre qui contiennent exactement \(k\) succès (touche nCr de la calculatrice). \(\binom{n}{0} = \binom{n}{n} = 1\), \(\binom{n}{1} = n\), \(\binom{n}{k} = \binom{n}{n-k}\), et \(\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}\) (triangle de Pascal).

Espérance et variance

\(E(X) = np\), \(V(X) = np(1 - p)\), \(\sigma(X) = \sqrt{np(1 - p)}\). Sur 100 pièces avec 3 % de défauts, on s'attend en moyenne à 3 pièces défectueuses.

Méthode : « au moins un »

\(P(X \geq 1) = 1 - P(X = 0) = 1 - (1 - p)^n\). Pour \(P(X \leq k)\) ou \(P(a \leq X \leq b)\), on utilise la calculatrice (« binomFRép » / « binomcdf »).

Fluctuation et loi des grands nombres

Quand \(n\) est grand, la fréquence \(\dfrac Xn\) des succès est très probablement proche de \(p\) : environ 95 % des fréquences observées tombent dans l'intervalle \[\left[p - 2\sqrt{\frac{p(1-p)}{n}}\,;\,p + 2\sqrt{\frac{p(1-p)}{n}}\right].\] Une fréquence en dehors de cet intervalle fait douter du modèle.

Exemple 2 — lot de composants

Un composant est défectueux avec probabilité 0,05. On en teste 20. Probabilité d'exactement 2 défectueux ? D'au moins un ? Nombre moyen de défectueux ?

Solution

\(X \sim \mathcal B(20\,;\,0{,}05)\). \(P(X = 2) = \binom{20}{2}0{,}05^2 \times 0{,}95^{18} = 190 \times 0{,}0025 \times 0{,}397 \approx 0{,}189\).

\(P(X \geq 1) = 1 - 0{,}95^{20} \approx 0{,}642\) ; \(E(X) = 20 \times 0{,}05 = 1\).

4. L'essentiel à retenir

Formulaire

  • \(P_A(B) = \dfrac{P(A \cap B)}{P(A)}\) ; probabilités totales ; indépendance \(P(A \cap B) = P(A)P(B)\).
  • \(E(X) = \sum x_ip_i\), \(V(X) = E(X^2) - E(X)^2\), \(\sigma = \sqrt V\) ; \(E(aX + b) = aE(X) + b\).
  • \(\mathcal B(n, p)\) : \(P(X = k) = \binom nk p^k(1-p)^{n-k}\), \(E = np\), \(V = np(1-p)\).
  • \(P(X \geq 1) = 1 - (1-p)^n\) ; 95 % des fréquences dans \(p \pm 2\sqrt{p(1-p)/n}\).

6. En prépa

Ce qui t'attend

  • Dénombrement : listes, arrangements, combinaisons, formule du binôme \((a+b)^n = \sum \binom{n}{k}a^kb^{n-k}\).
  • Formule de Bayes (exemple 1 b), lois géométrique et de Poisson.
  • Inégalité de Bienaymé-Tchebychev (déjà en spé maths générale) et loi faible des grands nombres.

Quiz

\(P(A) = 0{,}5\), \(P_A(B) = 0{,}4\). Alors \(P(A \cap B) =\)

  1. \(0{,}9\)
  2. \(0{,}8\)
  3. \(0{,}2\)
  4. \(1{,}25\)

\(P(A \cap B) = P(A) \times P_A(B)\).

\(X \sim \mathcal B(10\,;0{,}5)\). \(P(X = 0) =\)

  1. \(0{,}5^{10}\)
  2. \(0\)
  3. \(0{,}5\)
  4. \(10 \times 0{,}5\)

Dix échecs de suite : \((1 - p)^{10}\), soit \(\approx 0{,}001\).

L'espérance de \(\mathcal B(200\,;0{,}15)\) est :

  1. \(0{,}15\)
  2. \(170\)
  3. \(25{,}5\)
  4. \(30\)

\(np = 200 \times 0{,}15\). (25,5 est la variance \(np(1-p)\).)

Peut-on utiliser une loi binomiale pour le nombre de rois dans une main de 5 cartes tirées sans remise d'un jeu de 32 ?

  1. oui, toujours
  2. non : les tirages ne sont pas indépendants
  3. oui si on compte les dames
  4. non car il y a plus de 2 issues

Sans remise, la probabilité change à chaque tirage. On l'approche par une binomiale seulement si la population est très grande devant l'échantillon.
