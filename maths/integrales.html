Primitives et intégrales

Intégrer, c'est additionner une infinité de petites contributions : une aire, une énergie à partir d'une puissance, une distance à partir d'une vitesse, une valeur moyenne ou efficace. On calcule une intégrale grâce aux primitives.

Prérequis : formulaire de dérivation.

1. Primitives

Définition

\(F\) est une primitive de \(f\) sur un intervalle \(I\) si \(F' = f\) sur \(I\). Si \(F\) est une primitive, toutes les autres sont \(F + C\) avec \(C\) constante réelle.

Méthode : vérifier une primitive

On dérive le résultat : on doit retrouver \(f\). C'est le réflexe qui évite les erreurs de signe ou de coefficient.

Exemple 1

Trouver la primitive de \(f(x) = 6x^2 - \dfrac{4}{x} + e^{-2x}\) sur \(]0\,;+\infty[\) qui s'annule en \(1\).

Solution

\(F(x) = 2x^3 - 4\ln x - \dfrac12 e^{-2x} + C\). \(F(1) = 2 - 0 - \dfrac12 e^{-2} + C = 0\) donc \(C = \dfrac12 e^{-2} - 2\).

2. Intégrale et aire

Définition

Si \(f\) est continue sur \([a\,;b]\) et \(F\) une primitive de \(f\) : \[\int_a^b f(x)\,\mathrm{d}x = \big[F(x)\big]_a^b = F(b) - F(a).\] Si \(f \geq 0\) sur \([a\,;b]\), c'est l'aire (en unités d'aire) sous la courbe, entre \(x = a\) et \(x = b\).

Propriétés

  • Linéarité : \(\int_a^b (\alpha f + \beta g) = \alpha\int_a^b f + \beta\int_a^b g\).
  • Chasles : \(\int_a^b f + \int_b^c f = \int_a^c f\).
  • Positivité : si \(f \geq 0\) et \(a \leq b\), \(\int_a^b f \geq 0\). Là où \(f < 0\), l'aire compte négativement.
  • Aire entre deux courbes (\(f \geq g\)) : \(\int_a^b \big(f(x) - g(x)\big)\,\mathrm{d}x\).

Exemple 2

Calculer \(I = \int_0^2 (3x^2 - 2x + 1)\,\mathrm{d}x\) et \(J = \int_0^{\pi} \sin t\,\mathrm{d}t\).

Solution

\(I = \big[x^3 - x^2 + x\big]_0^2 = (8 - 4 + 2) - 0 = 6\).

\(J = \big[-\cos t\big]_0^{\pi} = -\cos\pi + \cos 0 = 1 + 1 = 2\).

3. Valeur moyenne et applications physiques

Valeur moyenne et valeur efficace

\[\mu = \frac{1}{b-a}\int_a^b f(t)\,\mathrm{d}t \qquad\qquad U_{\text{eff}} = \sqrt{\frac{1}{T}\int_0^T u(t)^2\,\mathrm{d}t}\]

Pour \(u(t) = U_{\max}\sin(\omega t)\) : moyenne nulle sur une période, \(U_{\text{eff}} = \dfrac{U_{\max}}{\sqrt2}\) (230 V efficaces ⇔ 325 V crête).

Intégrales en physique

  • Énergie à partir de la puissance : \(E = \int_{t_1}^{t_2} P(t)\,\mathrm{d}t\).
  • Distance à partir de la vitesse : \(x(t_2) - x(t_1) = \int_{t_1}^{t_2} v(t)\,\mathrm{d}t\).
  • Charge à partir de l'intensité : \(Q = \int i(t)\,\mathrm{d}t\).

Exemple 3 — énergie d'un moteur au démarrage

La puissance d'un moteur au démarrage vaut \(P(t) = 2\,000\big(1 - e^{-t}\big)\) W. Énergie consommée pendant les 3 premières secondes ?

Solution

\(E = \int_0^3 2000(1 - e^{-t})\,\mathrm{d}t = 2000\big[t + e^{-t}\big]_0^3 = 2000\big(3 + e^{-3} - 1\big) \approx 4\,100\) J.

5. En prépa

Ce qui t'attend

  • Intégration par parties : \(\int_a^b u v' = [uv]_a^b - \int_a^b u'v\). Ex. : \(\int_0^1 x e^{x}\,\mathrm{d}x = 1\).
  • Changement de variable, primitives de fractions rationnelles.
  • Théorème fondamental : \(x \mapsto \int_a^x f(t)\,\mathrm{d}t\) est la primitive de \(f\) qui s'annule en \(a\).

Quiz

Une primitive de \(f(x) = 4x^3\) est :

  1. \(12x^2\)
  2. \(x^4 + 7\)
  3. \(4x^4\)
  4. \(\dfrac{4x^4}{3}\)

\((x^4 + 7)' = 4x^3\). La constante peut être quelconque.

\(\int_1^e \dfrac{1}{x}\,\mathrm{d}x =\)

  1. \(e - 1\)
  2. \(0\)
  3. \(1\)
  4. \(-\dfrac{1}{e^2} + 1\)

\(\big[\ln x\big]_1^e = 1 - 0\).

Une primitive de \(\sin(2t)\) est :

  1. \(-\dfrac12\cos(2t)\)
  2. \(\cos(2t)\)
  3. \(-2\cos(2t)\)
  4. \(\dfrac12\cos(2t)\)

On vérifie en dérivant : \(\left(-\tfrac12\cos 2t\right)' = -\tfrac12 \times (-2\sin 2t) = \sin 2t\).

La valeur moyenne de \(f(x) = 2x\) sur \([0\,;4]\) est :

  1. \(16\)
  2. \(8\)
  3. \(2\)
  4. \(4\)

\(\dfrac{1}{4}\int_0^4 2x\,\mathrm{d}x = \dfrac{1}{4}\big[x^2\big]_0^4 = 4\).

\(\int_{-1}^{1} x^3\,\mathrm{d}x =\)

  1. \(\dfrac12\)
  2. \(0\)
  3. \(2\)
  4. l'aire sous la courbe, donc positive

Fonction impaire : les parties négative et positive se compensent. Une intégrale n'est une aire que si \(f \geq 0\).
