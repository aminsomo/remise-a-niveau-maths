Primitives et intégrales

L'intégrale additionne des petits morceaux : une aire sous une courbe, une énergie à partir d'une puissance, une charge à partir d'un courant, une distance à partir d'une vitesse. On la calcule grâce aux primitives (la « dérivation à l'envers »), et elle donne aussi la valeur moyenne et la valeur efficace d'un signal.

Prérequis : dérivation, primitives (1re).

1. Primitives

Définition

\(F\) est une primitive de \(f\) sur un intervalle \(I\) si \(F' = f\) sur \(I\). Toutes les primitives de \(f\) sont alors les \(F + C\) (\(C\) constante) ; une condition comme \(F(t_0) = y_0\) fixe \(C\). On vérifie toujours une primitive en la dérivant.

Tableau des primitives

\(f(x)\)une primitive \(F(x)\)\(f(x)\)une primitive \(F(x)\)
\(k\)\(kx\)\(x^n\) (\(n \neq -1\))\(\dfrac{x^{n+1}}{n+1}\)
\(\dfrac{1}{x}\) (\(x > 0\))\(\ln x\)\(\dfrac{1}{x^2}\)\(-\dfrac1x\)
\(e^x\)\(e^x\)\(e^{ax+b}\) (\(a \neq 0\))\(\dfrac1a e^{ax+b}\)
\(\cos(\omega x + \varphi)\)\(\dfrac{1}{\omega}\sin(\omega x + \varphi)\)\(\sin(\omega x + \varphi)\)\(-\dfrac{1}{\omega}\cos(\omega x + \varphi)\)
\(u'e^{u}\)\(e^{u}\)\(\dfrac{u'}{u}\) (\(u > 0\))\(\ln u\)
\(u'u^n\)\(\dfrac{u^{n+1}}{n+1}\)\(\dfrac{u'}{\sqrt u}\)\(2\sqrt u\)

Une primitive d'une somme est la somme des primitives ; celle de \(kf\) est \(kF\). Pour les formes « composées », il faut reconnaître \(u'\) devant (quitte à ajuster une constante).

Exemple 1

Trouver une primitive de \(f(x) = 3x^2 - \dfrac{2}{x} + e^{2x}\) sur \(]0\,;\,+\infty[\), puis de \(g(x) = \dfrac{2x}{x^2 + 1}\).

Solution

\(F(x) = x^3 - 2\ln x + \tfrac12 e^{2x}\). Pour \(g\), on reconnaît \(\dfrac{u'}{u}\) avec \(u = x^2 + 1 > 0\) : \(G(x) = \ln(x^2 + 1)\).

2. Intégrale et aire

Définition et calcul

Si \(f\) est continue et positive sur \([a\,;\,b]\), l'intégrale \(\displaystyle\int_a^b f(x)\,\mathrm{d}x\) est l'aire (en unités d'aire) du domaine compris entre la courbe, l'axe des abscisses et les droites \(x = a\) et \(x = b\). Dans tous les cas, si \(F\) est une primitive de \(f\) : \[\int_a^b f(x)\,\mathrm{d}x = \Big[F(x)\Big]_a^b = F(b) - F(a).\] Le « \(\mathrm{d}x\) » rappelle qu'on additionne des bandes de largeur infiniment petite \(\mathrm{d}x\) et de hauteur \(f(x)\).

Propriétés

  • Chasles : \(\displaystyle\int_a^b f + \int_b^c f = \int_a^c f\) ; et \(\displaystyle\int_a^a f = 0\), \(\displaystyle\int_b^a f = -\int_a^b f\).
  • Linéarité : \(\displaystyle\int_a^b (\alpha f + \beta g) = \alpha\int_a^b f + \beta\int_a^b g\).
  • Positivité : si \(f \geq 0\) sur \([a\,;\,b]\) (avec \(a \leq b\)), \(\displaystyle\int_a^b f \geq 0\) ; si \(f \leq g\), \(\displaystyle\int_a^b f \leq \int_a^b g\).
  • Si \(f\) est négative, l'intégrale est l'opposé de l'aire. Aire entre deux courbes (\(f \geq g\)) : \(\displaystyle\int_a^b (f - g)\).

Exemple 2

Calculer \(\displaystyle\int_0^2 (x^2 + 1)\,\mathrm{d}x\) et \(\displaystyle\int_0^{\pi} \sin x\,\mathrm{d}x\).

Solution

\(\Big[\tfrac{x^3}{3} + x\Big]_0^2 = \tfrac83 + 2 = \tfrac{14}{3} \approx 4{,}67\).

\(\Big[-\cos x\Big]_0^{\pi} = -\cos\pi + \cos 0 = 1 + 1 = 2\) : l'aire sous une arche de sinusoïde vaut exactement 2.

3. Valeur moyenne et applications physiques

Valeur moyenne et valeur efficace

La valeur moyenne de \(f\) sur \([a\,;\,b]\) est \(\mu = \dfrac{1}{b - a}\displaystyle\int_a^b f(x)\,\mathrm{d}x\) : c'est la hauteur du rectangle de même aire. La valeur efficace d'un signal périodique \(u\) de période \(T\) est \(U_{\text{eff}} = \sqrt{\dfrac{1}{T}\displaystyle\int_0^T u^2(t)\,\mathrm{d}t}\). Pour une sinusoïde d'amplitude \(U_m\) : moyenne nulle, \(U_{\text{eff}} = \dfrac{U_m}{\sqrt2}\).

Une intégrale « additionne » une grandeur

  • Énergie à partir de la puissance : \(E = \displaystyle\int_{t_1}^{t_2} p(t)\,\mathrm{d}t\).
  • Charge à partir de l'intensité : \(q = \displaystyle\int i(t)\,\mathrm{d}t\) ; distance à partir de la vitesse : \(d = \displaystyle\int v(t)\,\mathrm{d}t\).
  • Travail d'une force variable le long d'un axe : \(W = \displaystyle\int_{x_1}^{x_2} F(x)\,\mathrm{d}x\).

Exemple 3 — énergie d'une décharge

Une résistance reçoit la puissance \(p(t) = 50\,e^{-2t}\) (W, s). Énergie reçue entre 0 et 3 s ?

Solution

\(E = \displaystyle\int_0^3 50e^{-2t}\,\mathrm{d}t = \Big[-25e^{-2t}\Big]_0^3 = 25(1 - e^{-6}) \approx 24{,}9\) J.

Calcul approché : méthode des rectangles

On découpe \([a\,;\,b]\) en \(n\) bandes de largeur \(\dfrac{b - a}{n}\) et on additionne les aires des rectangles (hauteur prise au milieu de chaque bande) : plus \(n\) est grand, plus on s'approche de l'intégrale. C'est ce que fait l'animation ci-dessous, et ce que fait ta calculatrice.

4. L'essentiel à retenir

Formulaire

  • Primitives : \(x^n \to \dfrac{x^{n+1}}{n+1}\), \(\dfrac1x \to \ln x\), \(e^{ax+b} \to \dfrac1ae^{ax+b}\), \(u'e^u \to e^u\), \(\dfrac{u'}{u} \to \ln u\).
  • \(\displaystyle\int_a^b f = F(b) - F(a)\) ; aire si \(f \geq 0\) ; Chasles, linéarité, positivité.
  • Moyenne \(\mu = \dfrac{1}{b-a}\displaystyle\int_a^b f\) ; efficace \(\sqrt{\dfrac1T\displaystyle\int_0^T u^2}\), \(U_m/\sqrt2\) pour une sinusoïde.
  • \(E = \displaystyle\int p\,\mathrm{d}t\), \(q = \displaystyle\int i\,\mathrm{d}t\), \(d = \displaystyle\int v\,\mathrm{d}t\).

6. En prépa

Ce qui t'attend

  • Intégration par parties : \(\int_a^b u v' = [uv]_a^b - \int_a^b u'v\). Ex. : \(\int_0^1 x e^{x}\,\mathrm{d}x = 1\).
  • Changement de variable, primitives de fractions rationnelles.
  • Théorème fondamental : \(x \mapsto \int_a^x f(t)\,\mathrm{d}t\) est la primitive de \(f\) qui s'annule en \(a\).

Quiz

Une primitive de \(f(x) = 4x^3\) est :

  1. \(12x^2\)
  2. \(x^4 + 7\)
  3. \(4x^4\)
  4. \(\dfrac{4x^4}{3}\)

\((x^4 + 7)' = 4x^3\). La constante peut être quelconque.

\(\int_1^e \dfrac{1}{x}\,\mathrm{d}x =\)

  1. \(e - 1\)
  2. \(0\)
  3. \(1\)
  4. \(-\dfrac{1}{e^2} + 1\)

\(\big[\ln x\big]_1^e = 1 - 0\).

Une primitive de \(\sin(2t)\) est :

  1. \(-\dfrac12\cos(2t)\)
  2. \(\cos(2t)\)
  3. \(-2\cos(2t)\)
  4. \(\dfrac12\cos(2t)\)

On vérifie en dérivant : \(\left(-\tfrac12\cos 2t\right)' = -\tfrac12 \times (-2\sin 2t) = \sin 2t\).

La valeur moyenne de \(f(x) = 2x\) sur \([0\,;4]\) est :

  1. \(16\)
  2. \(8\)
  3. \(2\)
  4. \(4\)

\(\dfrac{1}{4}\int_0^4 2x\,\mathrm{d}x = \dfrac{1}{4}\big[x^2\big]_0^4 = 4\).

\(\int_{-1}^{1} x^3\,\mathrm{d}x =\)

  1. \(\dfrac12\)
  2. \(0\)
  3. \(2\)
  4. l'aire sous la courbe, donc positive

Fonction impaire : les parties négative et positive se compensent. Une intégrale n'est une aire que si \(f \geq 0\).
